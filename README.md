# GDRAGON QUEST · 월드 1 시제품

`index.html`을 Chrome 또는 Edge에서 열면 시작합니다. 빌드·설치·인터넷 연결 없이 실행할 수 있습니다. 배포할 때는 `index.html`, `css`, `js`, `assets`를 같은 상대 경로로 복사하세요. 내부 정적 웹 서버로 제공할 수도 있습니다.

- 이름 입력 → 인트로 → **고디월드 월드 선택** → **시작의 마을 스테이지 선택** → **캐릭터 대화** → 1-1~1-5 → 엔딩 순으로 플레이합니다.
- 시안의 지도·큰 캐릭터·크림색 입체 패널과 청록색 버튼을 기준으로 화면을 다시 구성했습니다. 월드 1 핀을 선택한 뒤 `스테이지 보기`, 원하는 스테이지의 `시작하기`를 누르세요.
- 단어/카드를 선택하고 빈칸/범주를 클릭하거나 드래그하세요. Tab과 Enter/Space로도 버튼을 조작할 수 있습니다.
- 설명·예제·힌트는 무료이고 재도전 감점은 없습니다. 완료한 스테이지는 지도에서 복습할 수 있습니다.
- 완료 단계뿐 아니라 배치·서술 답안·활동·대사 위치를 자동 저장합니다. 오른쪽 위 메뉴(≡)의 `진행 저장`으로 수동 저장할 수 있습니다. 메뉴의 `홈으로` → `이어서 모험하기`로 계속하세요. 이전 시제품의 저장 기록도 유지합니다.
- 월드 선택 화면의 스피커 버튼으로 짧은 효과음을 켜고 끕니다. 메뉴에서 전체 화면 전환·홈 이동·새 모험 시작을 제공합니다. 대화는 `다음`·`이전` 버튼이나 본문에 포커스가 있을 때 방향키·Space로 진행할 수 있습니다.
- 기록은 같은 브라우저·프로필·접속 경로에 저장됩니다. 파일 이동, 브라우저 데이터 삭제, 시크릿 모드 종료 등에 따라 사라질 수 있으며 중앙 이수 기록이 아닙니다. 저장 차단 시 화면 아래 안내가 표시됩니다.
- 1-5는 **실제 AI 채점 없는 예시 평가**입니다. 정해진 도구 선택과 이유 입력 여부만 확인하고 고정 피드백을 보여줍니다. 작성한 이유의 의미를 자동 평가하지 않습니다.
- 월드 2와 미니게임은 준비 중 표시만 제공합니다.

문항·대사는 `js/content.js`, 상태·판정·저장은 `js/core.js`, 화면은 `js/screens.js`, 문항 표현은 `js/activities.js`, 조작·전환은 `js/game.js`, 디자인은 `css/game.css`에서 관리합니다. 문항과 세부 결정은 [월드 1 구현설계](기획/월드1-구현설계.md)에 기록했습니다. 원본 시나리오·시안·이미지는 보존하고, UI 없는 월드 지도 `assets/backgrounds/godiworld-map-v2.png`를 추가했습니다.

## 검증

`tests/world1.html`은 실제 게임 화면을 조작하는 브라우저 회귀 검사입니다. 임시 테스트 브라우저 프로필에서 실행하세요. 같은 출처의 정적 서버에서 열거나, 로컬 자동 검사 시 브라우저의 파일 간 접근 허용 설정이 필요합니다. 게임 자체 실행에는 이 설정이 필요하지 않습니다.

실제 수행한 검증 결과와 한계는 `진행상황.md`에 기록합니다. 문항·표현·난이도는 시제품 초안이며 교육 담당자의 검수와 실제 사용자 시범 플레이가 남아 있습니다.

Windows에서 자동 검사는 프로젝트 폴더에서 다음 명령으로 실행할 수 있습니다. 실행 정책 옵션은 해당 검사 프로세스에만 적용됩니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests/run-browser.ps1
```

이 검사는 임시 브라우저 프로필에 가상 플레이 기록을 만들고 `tests/browser-result.html`에 결과를 저장합니다. 현재 사용자 프로필의 게임 저장 기록은 변경하지 않습니다.

- 월드 선택·스테이지 선택·캐릭터 대화화면의 구성을 변경한 뒤 **84개 검사 통과**. 현재 [브라우저 결과](browser-result.html)는 이 실행 결과입니다.
- 이전 저장의 새 필드 기본값 보완·답안 유지, 6개 월드 핀과 준비 중 잠금, 처음/복습의 시작 대화, 대화 중 새로고침, 홈/월드 이탈 및 복습 새로고침의 완료 보존을 추가 확인했습니다.
- [월드 선택](world-select-v2.png) · [스테이지 선택](stage-select-v2.png) · [대화화면](dialogue-v2.png) · [활동](activity-v2.png) · [390px 대화](dialogue-mobile-v2.png)를 캡처 검토했습니다. 모바일 상단을 두 줄로 바꿔 제목·버튼 겹침을 보완했습니다.
- 효과음은 로컬 합성음을 사용합니다. 소리 버튼의 설정 상태 변경은 확인했으며 실제 청취 품질과 사용자 기기의 전체 화면 동작은 후속 확인 대상입니다.

## 첫 구현 검증 이력

- `run-browser.ps1`로 실제 브라우저 회귀 검사 **62개 통과**. [브라우저 결과](browser-result.html).
- 이름 입력 → 인트로 → 지도 → 다섯 스테이지 → 엔딩 → 완료까지 실제 화면 버튼으로 진행했습니다.
- 이름 길이·유니코드·HTML/특수문자, 스테이지 잠금, 오답 수정, 무료 힌트·설명, 빈칸/카드 클릭과 DragEvent 배치, 이전 활동 유지, 더미 평가·이유 저장, 복습 완료 보존, 초기화 취소/확인을 확인했습니다.
- 실제 iframe 새로고침으로 대사·답안·엔딩 위치를 복구했습니다. 저장 차단·손상 JSON·지원하지 않는 버전은 별도 입력으로 확인했습니다.
- 게임 소스의 외부 URL·네트워크 호출 없음, 로컬 파일·사용 자산 존재를 확인했습니다.
- 390px에서 10개 활동의 가로 넘침 없음, [PC 홈](welcome-desktop.png)·[PC 마을](map-desktop.png)·[390px 활동](stage-mobile.png)의 캡처를 검토했습니다.

브라우저 실행은 제한된 환경에서 GPU 프로세스 차단으로 실패한 뒤 허용된 별도 실행에서 성공했습니다. 검사 스크립트는 Windows 기본 실행 정책과 한글 인코딩의 영향을 확인해 README에 실행 방법을 명시했습니다.

실제 기관망·계정·API·중앙 이수 기록, 터치 기기의 물리적 드래그, 스크린리더 전체 접근성, 인간 사용자의 난이도·소요 시간·학습 효과는 검증하지 않았습니다. 1-5 이유 서술의 의미는 평가하지 않는 예시 구현입니다.

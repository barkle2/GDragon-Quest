# 게임과 보상

[전체 기획안](기획안.md) · 관련 문서: [교육과 미션](교육과미션.md), [화면과 운영](화면과운영.md)

## 문서 상태

- **결정**: 사용자님이 동의한 방향입니다.
- **초안**: 기존 기획에서 유지하거나 구체화를 위해 제시한 내용입니다.
- **미정**: 별도 논의와 결정이 필요합니다.

## 월드 이야기와 성장

**결정**: 월드마다 해결할 사건을 두고, 선택과 조치에 따라 결과가 개선되는 모습을 보여줍니다. 레벨·배지 외에도 공간, 맡는 역할, 주변 반응 등의 변화로 성장을 표현합니다.

**초안 예시**: 월드 3에서는 잘못된 AI 보고서가 배포되기 전에 고드래곤과 내용을 바로잡습니다. 오류를 발견하고 적절한 조치를 취하면 보고서가 개선됩니다. 이 사건은 아직 확정되지 않았습니다.

**미정**: 월드별 사건, 등장인물, 대사, 공간 변화, 레벨별 변화, 전투·장비 도입 여부. 이야기의 완료 상태는 미션 진행 상태와 연결해 정합니다.

## 플레이와 재도전

- **결정**: 스테이지 중심 진행을 유지합니다. 주민의 부탁은 짧은 도입이며 자유 이동·별도 퀘스트 수락과 관리는 현재 시제품 범위에 넣지 않습니다. 월드·스테이지 버튼과 공통 문제 화면으로 모험을 표현합니다.

- **결정**: 학습 흐름은 설명 → 예제 → 도전 → 해설입니다. 잘못된 선택은 선택 → 결과 확인 → 설명 → 해당 단계 수정으로 이어집니다.
- **결정**: 여러 단계 미션에서 틀린 단계부터 수정하도록 설계합니다. 이미 완료한 단계와 읽은 설명의 유지 범위는 미정입니다.
- **초안 유지**: 재도전은 무제한이며, 실패 때문에 보유 보상이나 완료 미션을 초기화하지 않습니다.
- **초안 유지**: 동일 역량의 변형 문제를 제공하거나 해당 선택을 다시 하게 합니다. 변형 문제의 수와 제공 시점은 미정입니다.

## 진행과 잠금 해제 — 초안

1. 처음에는 1-1부터 시작합니다.
2. 미션을 통과하면 다음 미션이 열립니다.
3. 월드의 다섯 번째 미션은 앞선 내용을 연결하는 종합 관문입니다.
4. 완료 미션은 언제든 복습할 수 있습니다.
5. 첫 시제품의 마지막 미션을 완료한 뒤에는 완료 상태를 보여줍니다. 이후 월드의 화면 표시 방식은 미정입니다.

## 보상의 목적과 수량

**결정**: 보상별 목적과 레벨 상승에 따른 변화를 구체화합니다. 아래 목적·수량은 기존 초안이며 아직 확정한 지급 규칙이 아닙니다.

| 요소 | 목적 초안 | 기존 수량 초안 | 남은 결정 |
| --- | --- | --- | --- |
| XP | 레벨 성장과 진행 기록 | 미션당 100 XP, 월드 1 완료 보너스 100 XP | 레벨 구간과 변화, 보너스 적용 |
| 드래곤 코인 | 꾸미기 등 즐길 거리 | 미션당 10코인 | 사용처, 가격, 공급량 |
| 배지 | 월드 완료와 성취 표현 | 월드별 배지 | 이름, 디자인, 지급 조건 |
| 별 | 추가 성취 표현 후보 | 기존 1~3개 체계 | 유지 여부와 획득 방식 |

- **결정**: 힌트 사용으로 별점을 낮추지 않습니다. 상세 해설 다시 보기는 무료입니다.
- **결정**: 재도전 횟수에 따른 별점 감소는 재검토합니다. 기존 ‘첫 성공 3개/두 번째 2개/세 번째 이후 1개’ 규칙을 확정 규칙으로 사용하지 않습니다.
- **미정 후보**: 기본 완료로 별을 받고 선택형 추가 도전으로 더 얻는 방식. 선택형 도전을 이수 조건과 분리하는 안도 함께 검토합니다.
- **초안 유지**: 같은 문제를 반복 완료해 기본 보상을 중복 획득하지 않도록 합니다. 정확한 지급 시점과 예외는 미정입니다.
- **초안 유지**: 재도전 성공에 정규 XP 불이익을 주지 않습니다. 게임 보상은 실제 직무역량 점수로 해석하지 않습니다.

## 학습 도움과 상점

기존 상세 해설 열람용 ‘다시 보기 카드’ 유료화는 폐기합니다. 기본 힌트를 언제나 무료로 제공하는 세부 방식과 오답 제거·개념 조언 아이템의 취급은 추가 논의가 필요합니다. 힌트가 필요하다는 이유로 별점 불이익을 주지 않습니다.

**초안**: 꾸미기 아이템을 코인으로 구매합니다. 기존 고드래곤 장식 30~100코인 가격은 참고치이며 확정 가격이 아닙니다. 코인 부족 때문에 필수 학습 진행이 막히지 않도록 합니다.

## 미니게임

- **결정**: 첫 시제품은 미니게임 자리만 마련합니다. 실제 미니게임은 나중에 추가합니다.
- **미정**: 자리 개수, 배치, 준비 중 표시 방식, 추가 시기.
- **초안 유지**: 미니게임은 선택 활동이며 필수 미션 이수와 구분합니다. 홈의 ‘고드래곤 놀이터’나 월드 사이 휴식 공간은 배치 후보입니다.

| 기존 후보 | 내용 초안 |
| --- | --- |
| 넌센스 연구소 | 말장난·수수께끼 |
| 다른 그림 찾기 | 관찰력 게임 |
| 메모리 카드 | 카드 짝 맞히기 |
| 순발력 챌린지 | 제한 시간 안에 그림·숫자 순서 맞히기 |

기존 ‘5종 내외’는 목표 초안이며 구체적인 후보는 네 가지입니다. 코인 보상과 하루 획득 상한은 도입 여부부터 미정입니다.

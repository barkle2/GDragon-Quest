# 기술과 검증

[전체 기획안](기획안.md) · 관련 문서: [교육과 미션](교육과미션.md), [화면과 운영](화면과운영.md)

## 범위와 상태

이 문서는 기술 구상과 향후 검증 항목을 정리한 기획 문서입니다. 2026-10-15 월드 1 시제품은 외부 의존성 없는 HTML/CSS/JavaScript와 브라우저 localStorage로 구현했습니다. AGENTS.md에 따라 AI 에이전트가 소스와 검증 코드를 직접 관리합니다. 아래의 장기 기술 구상과 실제 시제품은 구분하며 현행 범위·더미 평가·저장 한계는 [월드 1 구현설계](월드1-구현설계.md), 실제 실행 검증은 [진행상황](../진행상황.md)을 기준으로 합니다.

**결정**: 첫 시제품은 월드 1의 5개 미션과 미니게임 자리입니다. 실제 미니게임은 나중에 추가합니다. 기존 MVP 10개 미션 안은 첫 시제품 기준으로 사용하지 않습니다.

## 시스템 구성 — 기존 초안

| 항목 | 구상 |
| --- | --- |
| 기본 기술 | HTML5, CSS3, JavaScript 또는 TypeScript |
| 화면 | 단일 페이지 웹 애플리케이션(SPA) |
| 문제 유형 | 단일·복수 선택, 연결, 순서 배열, 오류 탐지, 분기형 상황 |
| 콘텐츠 | 문항·조건·힌트·해설·영역 태그를 JSON으로 관리 |
| 판정 | 통과·부분점수·필수조건·보상을 구분해 처리 |
| 시제품 저장 | 브라우저 localStorage 후보 |
| 향후 운영 저장 | 계정 연동과 중앙 DB 후보 |

기술 선택, 운영 서버, 대상 브라우저와 네트워크 환경은 미정입니다. 실제 고용노동부 환경은 확인하지 않았습니다. 첫 시제품에 필요한 문제 유형부터 정하며 전체 유형을 한 번에 만드는 것으로 확정하지 않습니다.

## 콘텐츠와 채점

**최신 개정**: 월드 2~6의 수행형 상세안이 아래 과거 고정 채점 초안보다 우선합니다. 자유 요청·문서 편집·근거 연결·조건부 계획을 지원하는 방향이며 문자열 정답 일치만으로 판정하지 않습니다. 자유 산출물 의미 검토·규칙 검증·불확실 상태의 처리 방식은 아직 미정입니다. 실제 API 대화와 고정 시뮬레이션 기록을 구분합니다. 공통 기준은 [수행형 활동과 검토](수행형활동과검토.md)에 있습니다.

환경 보완: 사용자님은 내부망에서 연결 가능한 LLM API가 있다고 설명했습니다. 월드 2 상세안에는 실제 응답을 활용하는 직접 대화 후보를 포함하며 기존의 ‘모든 활동은 실제 AI 호출 없이 진행’ 구상은 고정형 활동에 한정해 재검토합니다. 연결·인증·브라우저 호출·자유 입력 평가와 완료 조건은 아직 미확인입니다. 사전 작성 예시를 사용하는 모드와 실제 API 응답은 구분해 표시합니다.

추가 검토: [스테이지 유형과 화면](스테이지유형과화면.md)에 직접 입력 대화형 후보를 작성했습니다. 기존 사전 제작 응답 방식과 실제 AI 미연결 초안을 자동으로 변경한 것은 아닙니다. 자유 입력의 응답 방식·완료 조건·저장·오류 처리는 별도 결정이 필요합니다.

**결정**: 고정 정답 배열 하나와 비교하지 않고 필수 내용, 허용 대안, 필수 순서·의존관계를 구분합니다. 여러 타당한 답을 인정합니다. 자동 채점의 구체적인 규칙과 부분점수는 미정입니다.

**결정**: 요청 → 결과 확인 → 재요청은 미리 작성한 응답을 이용한 연습용 시뮬레이션으로 구성하는 방향입니다. 응답이 실제 AI의 실시간 출력이라고 오해하지 않도록 안내합니다.

**기존 초안**: 실제 AI 모델 호출 없이 사전 제작한 콘텐츠와 규칙으로 판정합니다. 자유 입력 프롬프트나 기획서를 AI가 의미적으로 채점하는 기능은 기존 범위에 없습니다.

| 데이터 항목 초안 | 내용 |
| --- | --- |
| stageId / questionId | 미션·문항 식별자 |
| questionType | single, multi, match, sequence, hotspot, scenario |
| difficulty | 난이도 초안 |
| competencyWeights | 연습 영역과 가중치 후보; 표시·산정 여부 미정 |
| estimatedSeconds | 시간 기준을 구분한 예상 시간 |
| content | 상황, 자료, 선택지 |
| answerRule | 필수조건, 허용 대안, 순서, 부분점수 |
| hints / explanation | 단서와 정답·오답 이유 |
| variants | 재도전용 변형 문제 |
| version | 콘텐츠 개정 버전 |

자료 기준일·적용 조건과 사용 도구·허용 입력 조건은 문항에 반영합니다. 근거 자료·검수 상태 등의 추가 관리 항목은 초안 후보이며 필드명과 규격은 미정입니다.

## 상태 저장과 판정 — 초안

- 미션 시작·완료, 선택, 완료 단계, 힌트 상태를 분리해 저장 범위를 정합니다.
- 새로고침, 중단·재접속, 반복 제출 후의 복구와 중복 보상 처리를 확인합니다.
- 학습 기록과 XP·코인·배지는 서로 다른 목적으로 관리합니다.
- 향후 공식 운영의 최종 판정·이수 기록은 서버에서 처리하는 기존 안을 검토합니다. 브라우저 저장은 중앙 이수 증빙으로 가정하지 않습니다.
- 정답 조건을 미리 정하는 것과 클라이언트에 배포하는 것은 별개의 선택입니다. 시제품과 공식 운영의 판정 위치·보호 범위는 미정입니다.
- 사용자 식별키, 시도 결과, 시작·완료 시각, 도전·힌트 기록, 콘텐츠 버전과 이수 판정은 기존 저장 후보입니다. 수집 목적·최소 범위를 먼저 정합니다.

## 향후 단계 — 순서 초안

1. 월드 1의 5개 미션으로 설명·예제·도전·해설, 재도전, 고드래곤 안내와 보상 경험을 확인합니다. 미니게임은 자리만 제공합니다.
2. 월드 2~4 대표 미션으로 프롬프트 개선, 오류 대응, 복수 답안과 분기 흐름을 확인합니다.
3. 전체 확장을 결정하면 30개 미션과 변형 문제를 작성하고 교육·업무·AI 내용 검수를 진행합니다.
4. 운영 필요에 따라 로그인, 중앙 저장, 관리자 기능과 이수 판정을 설계합니다.
5. 시범운영 결과로 난이도·시간·설명을 조정하고 배포 범위를 정합니다.

첫 시제품 외 확장 범위와 일정은 미정입니다. 콘텐츠 관리시스템·조직별 분석·교육시스템 연동은 향후 후보이며, 별도 사전·사후 진단은 현재 추가하지 않습니다.

## 검증 항목 — 아직 수행하지 않음

- 수행형 산출물의 사실·근거·누락·조건 준수와 수정·유지 이유 확인.
- 예시와 다른 후속 자료·조건의 적용, 변화한 필드와 기존 필드 보존.
- 실제 AI 응답 변동·오류 없음·API 실패에 따라 적절한 피드백, 불필요한 재요청 강제 방지.
- 흐름 시험의 정상·누락·중복·정정·도구 실패 기대 결과와 실제 출력 비교.
- 의미 검토의 잘못된 승인·잘못된 수정 요구와 불확실 상태, 단일 LLM 점수 의존 방지.

- AI 초보자가 목표와 조작을 이해하고 1-1에 진입하는지.
- 설명 건너뛰기, 예제, 정답자·오답자 모두의 해설 흐름.
- 허용 대안, 필수조건 누락, 순서 의존관계, 부분점수 판정.
- 힌트 사용에 따른 별점 감점이 없는지, 확정한 보상 규칙과 중복 지급 처리.
- 틀린 단계 수정, 완료 단계 유지, 새로고침·재접속 복구.
- 카드의 클릭·키보드 대체 조작, 글자 확대, 대비와 브라우저 호환성.
- 콘텐츠 버전 변경과 기존 완료 기록의 관계.
- 향후 중앙 기록의 중복 저장·변조 대응과 권한 분리.

자동 테스트 코드가 필요하면 대화창으로 제공하며 사용자가 적용합니다. 현재 구현·자동 테스트·시범 플레이는 수행하지 않았습니다.

## 시간과 운영 목표

소요 시간의 정의와 미션별 기존 수치는 [교육과 미션](교육과미션.md)에서 관리합니다. 읽기·예제·도전·해설·재도전을 구분해 측정합니다.

| 기존 가설적 목표 | 현재 상태 |
| --- | --- |
| 1-1 최초 통과율 90% 이상 | 참고 초안; 실제 검증 전 |
| 월드 1 완료율 85% 이상 | 시작자 기준 참고 초안 |
| 전체 완료율 65% 이상 | 전체 확장 후 검토할 초안 |
| 재미·만족도 5점 중 4점 이상 | 참고 초안 |
| 미션 1~5분 | 기존 시간 가설; 새 학습 흐름에 맞춰 재산정 |

기존 사후 평가 평균 15%p 향상 목표는 현재 별도 진단을 하지 않는 방향에 맞춰 적용하지 않습니다. 참여·완료·게임 기록만으로 실제 직무역량 향상을 단정하지 않습니다.

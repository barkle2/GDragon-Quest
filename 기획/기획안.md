# GDRAGON-QUEST 기획안

고드래곤과 함께 배우고 도전하는 AI 업무 활용 게임 · 토론 반영본 · 2026-10-13

## 게임 소개

고용노동부 직원을 중심으로 하는 캐주얼 미션형 AI 학습 RPG입니다. AI를 한 번도 사용하지 않은 직원도 짧은 설명과 예제를 보고 업무 상황 속 선택을 연습할 수 있도록 설계합니다.

고드래곤과 사건을 해결하며 AI의 활용 범위, 요청 방법, 결과 검증, 업무 절차와 위험 대응을 익히는 방향입니다. 전체 구성은 기존 초안인 6개 월드·30개 미션을 유지하되 세부 내용은 계속 토론합니다.

## 결정한 핵심 방향

- 역량 강화 개정: 월드 1은 기초 판단 이유·새 사례 적용, 월드 2~6은 직접 산출물·검토 근거·후속 상황 대응 중심으로 진행합니다. OX·객관식은 보조 활동으로 두며 스테이지마다 3문제로 고정하지 않습니다. 공통 기준은 [수행형 활동과 검토](수행형활동과검토.md)에서 관리합니다.

- 스테이지 중심 구조를 유지합니다. 주민의 부탁은 짧은 도입 이야기이며 공통 화면에서 설명·예제·도전·해설을 진행합니다.
- 월드 1 ‘시작의 마을’은 AI 개념·데이터와 빅데이터·생성형 AI·LLM 특성을 중심으로 개편하는 방향입니다. 다섯 활동의 세부 내용은 검토 초안입니다.

- 대상은 고용노동부 직원이며 AI 미사용자도 포함합니다.
- 학습은 짧은 설명 → 예제 → 도전 → 해설로 진행합니다. 설명 건너뛰기를 제공하고 정답자에게도 이유를 설명합니다.
- 상세 해설 다시 보기는 무료이며 힌트 사용에 따른 별점 감점은 없습니다. 재도전 횟수에 따른 별점 감소는 재검토합니다.
- 틀린 단계에서 결과와 설명을 보고 수정합니다. 완료 단계 유지·저장 범위는 추가로 정합니다.
- 프롬프트 요소를 필수 공식으로 가르치지 않고 목적과 조건에 맞는 복수 답안을 인정합니다. 요청 → 결과 확인 → 재요청을 연습합니다.
- 오류 발견 이후 확인·수정·보류 행동을 다룹니다. 정책·규정에는 기준일과 적용 조건, 정보보호에는 사용 도구와 허용 입력 조건을 제시합니다.
- AI 지원과 직원의 확인·최종 판단을 구분하고 AI를 사용하지 않는 선택도 인정합니다.
- 월드별 사건과 공간·역할·주변 반응 등의 변화로 성장을 표현합니다. 구체적인 사건과 변화는 미정입니다.
- 월드 5~6에서는 제공된 상황에서 절차와 위험 대응을 판단합니다. 실제 자동화 구현이나 혁신 수행 전체를 측정한다고 표현하지 않습니다.
- 별도 사전·사후 진단은 추가하지 않습니다. 리포트는 게임에서 연습한 영역과 복습할 내용을 보여줍니다.

## 첫 시제품 범위 — 결정

- 월드 1의 5개 미션을 대상으로 합니다.
- 미니게임은 자리만 마련하고 실제 게임은 나중에 추가합니다.
- 월드 2~3 대표 미션이나 기존 MVP 10개 미션 안은 첫 시제품 범위에 포함하지 않습니다.

기술 선택, 보상 수량, 화면별 포함 범위, 저장 범위, 목표 기기와 접속 환경은 미정입니다. 이번 개정은 기획 문서 정리이며 소스코드 작성이나 시제품 제작을 시작한 것은 아닙니다.

## 이어서 정할 사항

1. 월드별 사건과 구체적인 성장 변화.
2. 미션별 목표 행동, 핵심 판단, 통과 기준과 허용 대안.
3. 별점 유지 여부와 보상 목적·지급·사용 규칙.
4. 단계 유지와 저장 범위, 목표 기기·접속 환경, 미니게임 자리 구성.
5. 정보보호 자료 선택과 내부 지침 반영 방식.
6. 리포트 표시와 공식 이수 운영 여부·기준.
7. 설명·해설·재도전을 구분한 목표 소요 시간과 근거 자료 확인.

기존 미션 표기 시간 합계는 95분이며 새 학습 흐름의 총시간은 아직 산정하지 않았습니다. 실제 콘텐츠 검수와 시범 플레이도 수행 전입니다.

# 수행형 활동과 검토 기준

[전체 시나리오](시나리오.md) · [교육과 미션](교육과미션.md)

## 승인한 방향과 설계 초안

사용자님이 승인한 방향은 입문 이해에서 독립적인 활용으로 성장하는 구성입니다. OX·객관식은 기초 확인과 보조 설명에 활용하고, 월드 2~6의 주요 활동은 직접 산출물·검토 근거·새 상황 적용을 중심으로 합니다. 아래 화면과 판정 방법은 구현 전 설계 초안입니다.

## 월드별 목표

| 월드 | 사용자가 할 수 있어야 하는 행동 | 남기는 증거 |
| --- | --- | --- |
| 1 | AI의 기초·한계와 자료 확인 필요성을 사례에서 설명 | 판단과 짧은 이유, 새 사례 적용 |
| 2 | 목적·자료·조건을 정해 요청하고 결과 개선 | 요청, AI 초안, 최종 문서, 수정·유지 이유 |
| 3 | 검증할 주장과 근거를 찾아 수정·보류 | 주장별 검토 기록, 근거 위치, 수정본 |
| 4 | 여러 자료로 요약·답변·보고를 완성 | 최종 산출물, 원문 대응, 수치 확인 |
| 5 | 작업 흐름을 구성하고 정상·예외 입력으로 시험 | 흐름, 시험 결과, 수정 이유 |
| 6 | 대안을 비교해 계획을 설명하고 조건 변화에 대응 | 대안 비교, 계획, 선택 근거, 수정안 |

## 공통 활동 흐름

1. 주민의 부탁을 받고 필요한 정보와 자료를 확인합니다.
2. 자료를 선택하고 AI·계산·규칙·사람에게 맡길 일을 구분합니다.
3. 실제 요청·편집·근거 연결·흐름 설계 등 스테이지 활동을 수행합니다.
4. 결과를 기준과 대조하고 필요한 부분만 수정합니다.
5. 결과물과 핵심 판단 이유를 주민에게 전달합니다.
6. 다른 자료 또는 추가 조건을 가진 후속 부탁으로 적용을 확인합니다.

필요한 단계만 조합합니다. 모든 스테이지에 전 단계를 강제하지 않습니다. 재요청 횟수·버튼 클릭 수·문장 길이 자체를 역량으로 평가하지 않습니다.

## 지원과 성장

- 초반에는 짧은 설명·예시·일부 채워진 양식을 제공합니다.
- 후반에는 예시 정답 대신 목표·자료·제약을 제공합니다. 힌트는 원할 때 볼 수 있으며 사용에 따른 별점 감점은 없습니다.
- 첫 결과가 기준을 충족하면 불필요한 수정·재요청을 요구하지 않습니다. 유지 이유를 설명해 검토 과정을 확인할 수 있습니다.
- 실수하면 해당 단계에서 수정하며 시간 제한·별도 사전·사후 시험은 추가하지 않습니다.
- 후속 부탁은 같은 스테이지 안의 이야기입니다. 결과물이 바뀌는지 보고 단순 예제 복사를 구분하는 설계이며, 모든 새 상황에 전이한다고 보장하지 않습니다.

## 완료·평가 설계

- 결과물: 필수 사실, 누락·충돌, 용도·형식·제약을 실제 내용에서 확인합니다.
- 과정: 자료 선택·근거 연결·수정 이유를 확인합니다. 좋은 결과가 우연히 나온 것인지 판단할 단서로 사용하며 사고 전체를 측정했다고 주장하지 않습니다.
- 후속 적용: 일부 조건이나 입력이 바뀌었을 때 결과와 판단을 갱신합니다.
- 예시 답안은 허용 가능한 사례입니다. 같은 문구·어순·도구 선택만 정답으로 강제하지 않습니다.
- 정확한 수치·ID·필수 필드·명시 조건은 규칙으로 확인하고, 자유 문장의 의미·근거 적합성은 별도 검토 기준이 필요합니다. LLM 단일 점수와 자기점검 체크만으로 완료를 확정하지 않습니다.
- 의미 판단 구현은 미정입니다. 검토가 불확실하면 추가 확인 필요로 표시하고 연습 제출과 검증 완료를 구분합니다. 인간 검토 운영을 새로 확정한 것은 아닙니다.
- 핵심 오류는 구체적인 위치·조건으로 피드백하고 수정 기회를 제공합니다. API 실패나 검토 시스템의 오류는 학습자 오답이 아닙니다.

## LLM과 시뮬레이션의 경계

내부망에서 연결 가능한 LLM API가 있다는 사용자 환경 설명을 전제로 실제 대화·초안 생성 활동을 설계합니다. 명세·인증·도구 기능·응답 품질·호출 제한은 미확인입니다. 기본은 텍스트 자료와 응답이며 첨부 파일 분석·검색·코드 실행 기능이 제공된다고 가정하지 않습니다.

주민의 질문·답변은 사전 제작된 정보 카드로 시작하는 구상입니다. 임의 질문을 이해하는 NPC 대화 AI는 별도 기능입니다. 흐름 시험은 게임 내 제한된 가상 기능을 실행하는 시뮬레이션이며 실제 자동화 시스템 구현이 아닙니다.

실제 API 응답과 사전 제작 예시를 구분합니다. 시뮬레이션만 수행한 기록을 실제 AI 수행과 같은 증거로 표시하지 않습니다. 모든 자료·숫자·정책은 가상 사례이며 실제 내부 지침과 법령 판단을 대신하지 않습니다.

## 필요한 공통 화면 — 초안

주민 대화, 정보 질문·메모, 자료 서랍, AI 대화, 문서 편집, 주장·근거 연결, 수치 확인, 단계 구성·시험, 대안 비교·계획 편집, 결과 피드백·완료가 후보입니다. 한 스테이지의 패널 전환으로 구성하고 자유 이동·퀘스트 관리 시스템은 추가하지 않습니다.

현재 이미지 시안이 이 모든 기능을 표현한 것은 아닙니다. 구현 순서·저장 범위·수집/보존 정책·시간·보상은 별도 확정합니다. 실제 학습 효과는 초보자와 숙련자의 플레이·산출물·후속 적용을 관찰해 확인해야 합니다.

# 스테이지 유형과 화면 시안

[전체 기획안](기획안.md) · [화면과 운영](화면과운영.md) · [월드 1 상세 시나리오](시나리오-월드1.md)

## 상태와 공통 구조

### 상세 시나리오의 유형 표시

각 스테이지 제목 바로 아래에 `유형`과 `보조`를 표시합니다. 객관식은 단일/복수 선택, OX는 참거짓 두 선택, 대화형은 질문 버튼 선택 또는 직접 문장 입력을 구분합니다. 서술형은 자신의 판단·요청·계획 작성, 편집형은 문서·표 수정, 근거 연결형은 주장과 자료 연결, 흐름 실행형은 단계 구성·시험입니다. 복합 수행형은 여러 유형을 연속 사용하는 활동입니다.

현재 월드 1 상세안에는 독립된 OX 활동이 없으며 객관식·연결·비교 활동을 유지합니다. OX 화면 시안이 있다는 이유로 실제 스테이지를 OX로 바꾸지는 않았습니다. 뒤 월드도 유형 표기를 위해 기존 수행 내용을 변경하지 않았습니다.

**최신 개정**: 월드 2~6은 [수행형 활동과 검토](수행형활동과검토.md)의 자료 선택·직접 요청·편집·근거 연결·흐름 시험·대안 계획으로 확장했습니다. 아래 다섯 유형 이미지와 배정표는 이전 시각 후보이며 최신 상세 시나리오를 대체하지 않습니다. 새로운 수행 UI는 아직 이미지 시안·구현 전입니다.

사용자님의 요청으로 진행 유형과 유형별 이미지 시안을 마련했습니다. 아래 분류·배정·규칙은 검토 초안입니다. 한 스테이지가 한 유형으로만 구성될 필요는 없으며, 학습 목표에 따라 여러 활동을 섞을 수 있습니다.

공통 흐름은 스테이지 선택 → 주민의 부탁 → 설명·예제 → 유형별 활동 → 해설·수정 또는 돌아보기 → 완료입니다. 이야기 대화화면은 모든 유형의 도입·완료에 사용할 수 있습니다.

기존 대화화면은 정해진 캐릭터 대사를 넘기는 이야기 화면입니다. 아래 직접 대화형은 사용자가 문장을 입력하는 활동 화면으로 구분합니다.

## 유형과 시안

| 유형 | 사용자 행동 | 적합한 활동 | 이미지 시안 |
| --- | --- | --- | --- |
| OX형 | 문장의 타당성을 O 또는 X로 선택 | 조건이 명확한 기초 개념·오해 확인 | [OX](시안/유형-OX-v1.png) |
| 선택형 | 하나 또는 여러 항목 선택 | 개념·기능·자료 조건 판단 | [선택형](시안/유형-선택형-v1.png) |
| 카드 분류형 | 카드 선택 후 분류 칸 지정 | 기능·작업·위험 항목 구분 | [카드 분류](시안/유형-카드분류-v1.png) |
| 자료 비교형 | 원본과 초안 대조 후 문장 상태·조치 선택 | 누락·왜곡·근거 확인 | [자료 비교](시안/유형-자료비교-v1.png) |
| 직접 대화형 | 요청 문장을 입력·전송하고 응답을 읽어 후속 요청 | LLM 입력 맥락·요청 개선 연습 | [직접 대화](시안/유형-직접대화-v1.png) |

연결·순서 배열·분기형 상황은 기존 후보로 유지합니다. 이번에는 위 다섯 유형의 대표 화면을 제작했으며 전체 유형 목록을 확정하거나 나머지를 폐기한 것은 아닙니다.

## 1. OX형

- 화면: 문장 하나, 동일한 크기의 O·X 선택 버튼, 제출, 설명 다시 보기·힌트.
- 시안 문항: ‘AI가 만든 답은 항상 정확하다.’ 정답 초안은 X입니다.
- 동작: 선택 상태를 표시한 뒤 제출합니다. 정답에도 이유를 제공하고 오답은 같은 문항을 다시 선택합니다.
- 작성 기준: 상황에 따라 참·거짓이 달라지는 표현은 조건을 붙입니다. 단순한 OX 선택 결과만으로 학습 이해를 단정하지 않습니다.

## 2. 선택형

- 단일선택은 하나만, 복수선택은 여러 항목을 선택하도록 안내를 구분합니다.
- 시안은 복수선택입니다. 자료의 대상·기간과 누락·오류 확인을 선택하고 ‘자료가 많으면 무조건 정확함’은 제외합니다.
- 체크 상태는 정답 여부가 아니라 사용자의 현재 선택 상태입니다. 시안은 제출 전 예시이며 정답이 미리 선택되는 초기 화면을 뜻하지 않습니다.
- 제출 후 필수 선택·허용 대안·제외 항목 규칙에 따라 해설합니다. 부분점수와 통과 조건은 미정입니다.
- 시안에 빠진 공통 도움 버튼은 실제 UI 설계에서 설명 다시 보기·힌트 위치를 통일합니다.

## 3. 카드 분류형

- 화면: 분류할 카드와 이름이 붙은 칸, 선택 상태, 분류 확인 버튼.
- 시안: 새 안내문·그림은 ‘새 내용 생성’, 원본 찾기·정해진 합계는 ‘기존 자료 조회·계산’에 배치하는 작동 사례입니다.
- 카드를 클릭하고 칸을 클릭하는 방식 또는 카드별 선택 메뉴로 조작합니다. 드래그만 요구하지 않으며 키보드 대체 조작도 설계합니다.
- 카드 이동 취소·다시 배치가 가능하도록 합니다. 미배치 상태와 완료 상태를 구분합니다.
- 이 분류는 제시된 행동을 구분하는 것이며 검색·계산에 AI가 결합될 수 없다고 가르치는 화면이 아닙니다.

## 4. 자료 비교형

- 화면: 원본과 초안의 두 영역, 문장별 상태 선택, 검토 결과 확인.
- 시안의 오전 10시와 오후 2시는 ‘다름’, 무료는 ‘일치’, 기념품 약속은 ‘근거 없음’으로 분류합니다.
- 자료에 근거가 없는 내용과 거짓으로 확인된 내용은 구분합니다. 후속 조치에서 삭제 후 게시·확인 전 보류 등 허용 대안을 다룰 수 있습니다.
- 작은 화면에서는 자료 탭이나 위아래 배치 후보를 검토합니다. 색뿐 아니라 선택 문구로 상태를 표시합니다.
- 현재 시안은 자료를 축약한 대표 화면입니다. 기존 1-5의 네 문장과 전체 판정을 대체한 것이 아닙니다.

## 5. 직접 대화형

- 화면: 주민 부탁과 참고 자료, 대화 기록, 자유 문장 입력창, 보내기, 대화 돌아보기.
- 시안은 사용자가 요청을 입력하는 화면이며 응답은 설명용 예시입니다. 실제 AI 연결·서버·자동 평가가 구현된 상태가 아닙니다.
- 기존 1-4는 사전 작성 요청·응답을 선택해 비교하는 방식입니다. 직접 입력을 받는 방식은 추가 후보이며 기존 문제를 자동으로 교체하지 않습니다.
- **응답 방식 미정**: 실제 AI 응답을 연결할지, 제한된 연습 시나리오를 사용할지 결정해야 합니다. 자유 입력에 단순 고정 응답을 돌려주면서 실제 대화처럼 표현하지 않습니다.
- **완료·평가 미정**: 문장 일치 채점은 사용하지 않는 방향을 제안합니다. 대화 참여·조건 확인·돌아보기 또는 별도의 판단 문제로 마무리할지 논의합니다.
- 다음 설계에서 빈 입력·전송 중·응답 지연·오류·재시도·중단 복원 상태, 입력 길이와 기록 저장 범위를 정합니다.
- 게임 내 이름의 7자 제한은 대화 입력 길이에 적용하지 않습니다. 직접 대화 입력 길이는 별도 미정입니다.

## 월드 1 배정 제안

| 스테이지 | 중심 유형 후보 | 보조 활동 |
| --- | --- | --- |
| 1-1 AI를 만나다 | OX·선택형 | 기능 사례 연결 |
| 1-2 데이터에서 배우다 | 선택형 | 기록표 품질 확인 |
| 1-3 새로운 것을 만들다 | 카드 분류형 | 기능 조건 선택 |
| 1-4 LLM과 대화하다 | 직접 대화형 후보 | 기존 사전 작성 요청·응답 비교는 유지 가능한 대안 |
| 1-5 그럴듯해도 확인하기 | 자료 비교형 | 후속 조치 선택·분기 |

기존 15개 상세 문제는 유지합니다. 유형 배정이 확정되면 문항·판정·화면 흐름을 함께 수정합니다. 시안의 ‘문제 1 / 3’도 기존 초안을 반영한 예시이며 모든 유형이 3문제여야 한다는 확정 규칙이 아닙니다.

## 검토 결과와 다음 결정

대표 재설계: [월드 2의 2-5](시나리오-월드2.md)는 질문·자료 선택·직접 요청·근거 연결·편집·최종안 전달을 조합하는 수행형 후보입니다. 기존 직접 대화 시안만으로 자료 서랍·편집·검토 UI까지 준비된 것은 아니며 해당 화면의 설계가 추가로 필요합니다.

- 다섯 유형 모두 기존 민트·크림색과 따뜻한 마을 배경을 유지해 생성했습니다. 이미지에서 조작 방식과 주요 문구를 시각 확인했습니다.
- 화면 제목·배치·선택 상태는 시안입니다. 이미지 안의 텍스트·아이콘·캐릭터를 실제 구현에서는 개별 UI와 자산으로 분리합니다.
- 후속 결정: 유형 목록·월드 1 배정, 직접 대화의 응답 방식과 완료 조건, 도움 버튼 통일, 모바일 배치와 조작 상태.
- 정적 이미지 다섯 개를 저장했으며 소스코드·자동 테스트·실제 대화·조작 검증은 수행하지 않았습니다.

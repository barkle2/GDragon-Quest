- 현재 남아 있는 **총 20개** 문항을 **앞쪽 1-1 개념 이해 11개**, **뒤쪽 1-4 대화·활용 요령 9개**로 분류했습니다. 실제 출제 수나 필수 순서는 확정하지 않습니다.

- LLM·컨텍스트 자체를 정의하는 문제는 포함하지 않습니다. 해당 개념은 별도 단계인 1-3에서 다룹니다.

### 예시 1 — AI는 어떤 기술일까요?//1-1출제

**문항 ID**: `1-1-E01`  
**관련 개념**: 인공지능(AI)의 기본 개념

**문제**

> AI(인공지능)는 사람의 [① ______]이 필요한 일을 [② ______]로 수행하도록 만드는 기술이에요. 사진 속 대상을 알아보는 AI는 다양한 [③ ______]에서 공통된 [④ ______]을 익힐 수 있어요.

**제시 카드 — 8개**

{감정} · {컴퓨터} · {우연} · {데이터} · {로봇} · {패턴} · {지능} · {직감}

**정답 — 빈칸 순서**: ① 지능 / ② 컴퓨터 / ③ 데이터 / ④ 패턴

**오답 카드 — 4개**: 감정 / 우연 / 로봇 / 직감

**완성 문장**

> AI(인공지능)는 사람의 지능이 필요한 일을 컴퓨터로 수행하도록 만드는 기술이에요. 사진 속 대상을 알아보는 AI는 다양한 데이터에서 공통된 패턴을 익힐 수 있어요.

**고디의 힌트**: “사진 속 대상을 알아보려면 여러 사진에서 공통된 특징을 익혀야 해!”

**나래의 해설**: “AI는 글을 쓰는 도구뿐 아니라 사진 속 대상을 알아보는 기술도 포함해요. 예시의 AI는 데이터에서 패턴을 익혀 작동하며, 로봇의 몸체가 꼭 필요한 것은 아니에요.”

### 예시 5 — 머신러닝은 무엇을 배우는 기술일까요?

**문항 ID**: `1-1-E05`  
**관련 개념**: 머신러닝 — 데이터에서 배워 새 자료에 적용

**문제**

> 머신러닝은 컴퓨터가 사진이나 글 같은 [① ______]에서 배우는 기술이에요. 고양이와 강아지 사진을 보며 귀나 얼굴 모양 같은 [② ______]을 익히는 과정을 [③ ______]이라고 해요. 이렇게 배운 내용으로 처음 보는 사진 속 동물이 무엇인지 [④ ______]할 수 있어요.

**제시 카드 — 8개**

{판단} · {복사} · {데이터} · {직감} · {학습} · {감정} · {특징} · {삭제}

**정답 — 빈칸 순서**: ① 데이터 / ② 특징 / ③ 학습 / ④ 판단

**오답 카드 — 4개**: 감정 / 직감 / 복사 / 삭제

**완성 문장**

> 머신러닝은 컴퓨터가 사진이나 글 같은 데이터에서 배우는 기술이에요. 고양이와 강아지 사진을 보며 귀나 얼굴 모양 같은 특징을 익히는 과정을 학습이라고 해요. 이렇게 배운 내용으로 처음 보는 사진 속 동물이 무엇인지 판단할 수 있어요.

**고디의 힌트**: “고양이랑 강아지를 구별할 땐 귀나 얼굴 모양을 살펴보지? AI도 여러 사진에서 이런 단서를 배워 새 사진을 구별하는 데 쓰는 거야!”

**나래의 해설**: “사진이나 글은 머신러닝이 배우는 데 쓰는 데이터예요. 고양이와 강아지의 귀나 얼굴 모양 같은 특징을 익히는 과정이 학습이고, 배운 내용을 새 사진에 적용해 어떤 동물인지 판단할 수 있어요. 다만 학습했다고 모든 사진을 정확하게 구별하는 것은 아니에요.”

### 예시 6 — 학습한 내용을 활용하는 모델은 무엇일까요?

**문항 ID**: `1-1-E06`  
**관련 개념**: 학습된 모델

**문제**

> 머신러닝으로 학습한 뒤, 익힌 내용을 활용해 작동하는 것을 학습된 [① ______]이라고 해요. 가게 사진을 구별하도록 학습했다면, 새로운 사진을 [② ______]으로 받아 학습한 [③ ______]을 활용하고 판단 결과를 [④ ______]으로 내놓을 수 있어요.

**제시 카드 — 8개**

{출력} · {사진첩} · {검색 기록} · {패턴} · {모델} · {화면} · {입력} · {정답표}

**정답 — 빈칸 순서**: ① 모델 / ② 입력 / ③ 패턴 / ④ 출력

**오답 카드 — 4개**: 사진첩 / 검색 기록 / 화면 / 정답표

**완성 문장**

> 머신러닝으로 학습한 뒤, 익힌 내용을 활용해 작동하는 것을 학습된 모델이라고 해요. 가게 사진을 구별하도록 학습했다면, 새로운 사진을 입력으로 받아 학습한 패턴을 활용하고 판단 결과를 출력으로 내놓을 수 있어요.

**고디의 힌트**: “학습한 뒤 새로운 자료에도 결과를 내놓는 역할을 해. 자료가 들어가고 결과가 나오는 흐름을 떠올려 봐!”

**나래의 해설**: “학습된 모델은 학습 과정에서 조정된 구조와 값을 이용해 입력을 처리해요. 원본 사진을 모아 둔 사진첩이나 정답표 자체와는 구분되며, 새로운 사진에 대한 판단도 틀릴 수 있어요.”

### 예시 7 — 배우는 단계와 사용하는 단계는 같을까요?//1-1출제

**문항 ID**: `1-1-E07`  
**관련 개념**: 학습과 추론(사용 단계)

**문제**

> 모델이 자료에서 패턴을 익히도록 조정되는 과정은 [① ______]이에요. 학습이 끝난 모델에 새 자료를 넣어 결과를 얻는 과정은 [② ______]이라고 해요. 이때 새로 건넨 자료는 [③ ______]이고, 모델이 내놓은 결과는 [④ ______]이에요.

**제시 카드 — 8개**

{저장} · {출력} · {복사} · {추론} · {삭제} · {입력} · {학습} · {압축}

**정답 — 빈칸 순서**: ① 학습 / ② 추론 / ③ 입력 / ④ 출력

**오답 카드 — 4개**: 저장 / 복사 / 삭제 / 압축

**완성 문장**

> 모델이 자료에서 패턴을 익히도록 조정되는 과정은 학습이에요. 학습이 끝난 모델에 새 자료를 넣어 결과를 얻는 과정은 추론이라고 해요. 이때 새로 건넨 자료는 입력이고, 모델이 내놓은 결과는 출력이에요.

**고디의 힌트**: “예시를 보며 배우는 때와, 배운 것을 새 문제에 적용하는 때를 나눠 봐!”

**나래의 해설**: “학습은 모델을 조정하는 과정이고, 추론은 학습된 모델로 입력을 처리해 결과를 얻는 과정이에요. 질문이나 자료를 한 번 입력하는 것이 곧바로 모델 자체를 다시 학습시킨다는 뜻은 아니에요.”

### 예시 9 — 편향을 줄이려면 어떤 자료를 살펴야 할까요?//1-1출제

**문항 ID**: `1-1-E09`  
**관련 개념**: 데이터 편향 — 치우친 자료와 빠진 상황

**문제**

> 데이터 편향은 학습 자료가 [① ______] 상태예요. 낮 사진만 배운 AI는 밤 사진처럼 [② ______]에서는 오류가 생길 수 있어요. 이를 줄이려면 낮 사진만 더 모으기보다 [③ ______]를 포함하고, 낮과 밤 각각에서 [④ ______]을 확인해야 해요.

**제시 카드 — 8개**

{파일 크기} · {충분히 배우지 못한 상황} · {고르게 모인} · {조건별 성능} · {같은 조건의 자료} · {한쪽으로 치우친} · {익숙한 상황} · {여러 조건의 자료}

**정답 — 빈칸 순서**: ① 한쪽으로 치우친 / ② 충분히 배우지 못한 상황 / ③ 여러 조건의 자료 / ④ 조건별 성능

**오답 카드 — 4개**: 파일 크기 / 고르게 모인 / 같은 조건의 자료 / 익숙한 상황

**완성 문장**

{자동 승인} · {원문} · {확인 필요} · {답변 길이} · {출처} · {정답 보장} · {대조} · {추측한 정답}

**정답 — 빈칸 순서**: ① 출처 / ② 원문 / ③ 대조 / ④ 확인 필요

**오답 카드 — 4개**: 자동 승인 / 답변 길이 / 정답 보장 / 추측한 정답

**완성 문장**

> 문서 기반 답변을 확인할 때는 참고한 자료가 어디인지 알려 주는 출처를 살펴봐요. 표시된 파일이나 링크를 따라 원문을 열고, 답변 내용과 대조해야 해요. 자료에 답이 없다면 확인 필요로 남겨야 해요.

**고디의 힌트**: “어느 자료를 참고했는지 찾아가 봐. 출처가 있다고 끝내지 말고 그 내용이 답을 뒷받침하는지 확인하는 거야!”

**나래의 해설**: “출처 표시를 요청하고, 실제 문서가 답변을 뒷받침하는지 확인해야 해요. 모든 문서 기반 AI가 출처를 같은 방식으로 보여 주는 것은 아니며, 문서를 참고해도 오류나 누락이 생길 수 있어요.”

## 기획·검수 메모

- 문항별로 네 빈칸의 위치까지 정답과 일치하는지 확인하는 고정 정답 대조 방식입니다. 내부 GPT 채점이나 실제 AI 호출을 요구하지 않습니다.
- 카드 수·정답 대조와 별개로, 실제 초급 학습자가 문장을 이해하는지와 풀이 시간은 시범 적용으로 확인해야 합니다. 20개를 모두 필수로 사용한다는 의미는 아닙니다.
- AI 전체를 머신러닝과 동일시하지 않으며, 자료 입력과 모델 학습을 구분합니다. 또한 AI 결과의 정확성을 보장하거나 데이터 수량만으로 품질을 판단하는 문장을 사용하지 않습니다.
- 본 문서는 예시 초안입니다. 원래 시나리오의 오답 처리·재도전 정책과 실제 게임 문항은 변경하지 않습니다.

- 비슷한 주제의 문항은 비교·선택용 대안입니다. 머신러닝은 5·21번, 프롬프트는 8·16번, 할루시네이션의 뜻과 사례는 31·32번을 비교해 고를 수 있습니다. 10·17·19·28번은 답변 확인 방법을 서로 다른 상황에서 다루는 1-4 후보입니다. 기존 번호의 빈자리는 채우거나 다시 번호를 붙이지 않았습니다.

## 시작 전 — 인트로와 첫 만남

// 수정하기(설명문 추가, 고디와 나 대화 수정)
설명문: “오래 전부터 여러 종족의 주민들이 함께 살아온 고디월드에, 최근 AI라는 새로운 기술이 등장했습니다. 당신은 고디월드 왕국지원단 일꾼으로서 고드래곤과 함께 주어진 업무를 완수해 나가야 합니다.”

이름 입력: “당신의 이름을 알려주세요: ____________” — 사용자 지정, 7자 이내. 이후 `{사용자명}`으로 표시합니다. 최소 길이·허용 문자·저장 방식은 미정입니다.

- 고드래곤: “안녕? 네가 바로 {랜덤수식어}로 유명한 {사용자명} 이구나? 반가워 난 고드래곤이라고 해. 줄여서 고디라고 불러도 좋아.”
- 나: “내가 {랜덤수식어}로 유명하다고? 난 금시초문인데?”
- 고디: “알아알아 뭘 부끄러워하고 그래~”
- 나: “아니 정말...”

수식어는 가벼운 허풍이며 같은 장면에서 동일한 값을 사용합니다. 목록·선정·저장 범위는 미정입니다.

나래가 주인공의 말을 끊으며 등장합니다.

// 나래의 미션 소개, 고디와 나 속마음 수정하기
- 나래: “거기 고드래곤! 그리고 {사용자명}! 한가하게 수다 떨 시간이 없어요! 축제까지 시간이 얼마 남지 않았다고요!”
- 나래: “자 두 분은 이제 한 팀으로 움직이는 거예요! 그러니까 사이좋게 지내요! 그리고 할 일이 뭔지는 이미 들었죠?”
- 고디&나: “아뇨... 아직 못 들었...”
- 나래: “뭐라고요? 아니 또 누가 일을 엉망으로 한거야! 에휴 할 수 없죠. 바쁘니까 한번만 설명할테니 잘 들어요!”
- 나래: “둘은 이제부터 고디월드의 가장 중요한 행사인 봄맞이축제를 성공시켜야 해요. 부담스럽다구요? 걱정말아요. AI와 함께 진행해 볼 거예요.”
- 나래: “AI를 어떻게 쓸 지 잘 모른다는 표정이네요? 걱정하지 마세요! 지금부터 고디월드를 돌아다니면서 알려줄테니까요!”
- 나&고디: “(정말 활달한 분이네...)”

1-1을 선택하는 화면으로 이동합니다. ‘한번만’은 성격을 보여주는 대사이며 다시 보기를 제한하지 않습니다. 축제의 긴박함을 실제 제한시간으로 적용하지 않습니다.

## 1-1 — AI의 개념

**유형: 드래그 빈칸 채우기**

### 진행 형태

| 항목 | 방식 |
| --- | --- |
| 중심 활동 | 학습 원리 → 답변 생성 → 정확성과 검증의 핵심 개념 완성 |
| 화면·조작 | 문항별 빈칸 3~4개, 후보 단어 6~8개, 드래그 배치·수정·확인 |
| 순서 | 구분별 후보 선정 → 구분 1·2·3 순서로 카드 배치·확인 → 완성 문장·해설 → 필요한 수정 |
| 제출 | 출제된 3문항의 빈칸 배치 결과 |
| AI 사용 | 고정 자료·정답 대조, LLM 호출 없음 |

**상황**: 실전 업무를 시작하기 전에 나래가 AI가 어떤 기술인지 설명합니다.

**추가 대사 초안**:

나래, 고디, 나는 월드 1에 도착한다.
- 나래: "고디월드의 왕국지원단이 되신걸 축하해요! 이곳에서는 AI가 무엇이고 어떤 일을 할 수 있는지, 답은 어떻게 만드는지, 어떻게 활용할 수 있는지 알아볼 거예요. 그럼 왕국지원단으로서 축제 준비를 위한 첫걸음을 시작해볼까요?"
- 나래: "이제 출발!"
출발! 버튼을 눌러 스테이지 1-1로 이동한다.

- 나래: “고디와 {사용자명}는 AI에 대해 얼마나 알고 계신가요? AI가 어떤 기술인지부터 알아가봅시다!”
- 고디: "넵!/좋아요!"
넵!/좋아요! 두 버튼이 나온다. 어느 버튼을 클릭하든 문제 페이지로 이동한다.

(문제 풀기)
- 나래: "AI의 개념을 설명하는 문장에 빈칸이 있어요. 아래 카드들 중에서 빈칸에 가장 적절한 카드를 골라 채워주세요!"
다음 버튼을 누르면 문제 페이지로 이동한다.

문제 페이지는 문제 설명, 빈칸있는 문장, 빈칸 카드들이 있는 구성이다.
정답과 오답이 섞인 카드 중에서 빈칸에 알맞은 카드를 골라 빈칸에 드래그한다.
문제 설명: 단어를 고른 뒤 빈칸을 누르거나, 단어를 끌어서 빈칸에 놓으세요.
카드를 알맞게 놓으면 빈칸에 카드의 글자가 입력되고, 틀리게 놓으면 카드가 튕겨져나가 제자리로 돌아간다.


### 출제 구성

후보는 총 6문항이며, 세 구분에서 각각 한 문항씩 무작위로 골라 총 3문항을 출제한다. 학습 순서는 아래와 같이 고정한다.

| 학습 순서 | 구분 | 후보 문제 | 출제 수 |
| --- | --- | --- | --- |
| 1 | AI는 어떻게 학습할까? | 문제 1 — 후보 A / 문제 2 — 후보 B | 1문항 |
| 2 | 생성형 AI는 어떻게 답변할까? | 문제 3 — 후보 A / 문제 4 — 후보 B | 1문항 |
| 3 | AI의 답변은 항상 정확할까? | 문제 5 — 후보 A / 문제 6 — 후보 B | 1문항 |

- A형은 빈칸 4개·후보 카드 8개, B형은 빈칸 3개·후보 카드 6개로 구성한다.
- 후보 카드에는 정답과 오답을 섞어 제시한다.
- 아래 문제 번호와 A/B 표시는 후보를 구분하기 위한 것이다. 학습자는 선택된 3문항을 차례대로 푼다.
- 같은 문항을 다시 풀 때는 선택된 후보를 유지한다. 오답 때 다른 후보로 바꾸지 않는다.
- 문항별 정답·오답 구분, 완성 문장, 고디의 힌트는 학습자 화면에 처음부터 표시하지 않고 아래 피드백 규칙에 따라 사용한다.

나는 문제를 푼다.

### 문제 후보와 고디의 힌트

#### 구분 1 — AI는 어떻게 학습할까?

**문제 1 — 후보 A**

> AI는 많은 [① ______]를 학습해 그 안에 담긴 [② ______]을 찾아냅니다. 이러한 학습 방식 중 하나가 [③ ______]이며, 학습한 내용을 활용해 처음 접하는 상황에서도 [④ ______]을 할 수 있습니다.

**제시 카드 — 8개**

{데이터} · {패턴} · {머신러닝} · {예측} · {명령어} · {저장공간} · {복사} · {암기}

**정답 — 빈칸 순서**: ① 데이터 / ② 패턴 / ③ 머신러닝 / ④ 예측

**오답 카드 — 4개**: 명령어 / 저장공간 / 복사 / 암기

**완성 문장**

> AI는 많은 데이터를 학습해 그 안에 담긴 패턴을 찾아냅니다. 이러한 학습 방식 중 하나가 머신러닝이며, 학습한 내용을 활용해 처음 접하는 상황에서도 예측을 할 수 있습니다.

**고디의 힌트**: “여러 예시에서 공통점을 배워두면, 처음 보는 상황에서도 결과를 예상하는 데 쓸 수 있겠지?”

---

**문제 2 — 후보 B**

> 머신러닝은 컴퓨터가 [① ______]에서 반복되는 특징과 규칙인 [② ______]을 익히는 방법입니다. 이러한 배움의 과정을 [③ ______]이라고 하며, 배운 내용은 처음 보는 자료를 처리할 때도 활용할 수 있습니다.

**제시 카드 — 6개**

{저장} · {패턴} · {명령어} · {학습} · {데이터} · {복사}

**정답 — 빈칸 순서**: ① 데이터 / ② 패턴 / ③ 학습

**오답 카드 — 3개**: 저장 / 명령어 / 복사

**완성 문장**

> 머신러닝은 컴퓨터가 데이터에서 반복되는 특징과 규칙인 패턴을 익히는 방법입니다. 이러한 배움의 과정을 학습이라고 하며, 배운 내용은 처음 보는 자료를 처리할 때도 활용할 수 있습니다.

**고디의 힌트**: “자료에서 반복되는 특징을 찾아 익히는 과정을 떠올려봐. ‘배운다’는 뜻과 연결되는 카드도 있을 거야!”

#### 구분 2 — 생성형 AI는 어떻게 답변할까?

**문제 3 — 후보 A**

> 생성형 AI는 학습한 [① ______]을 바탕으로 새로운 내용을 [② ______]합니다.  앞서 나온 내용의 [③ ______]을 고려하고, 다음에 올 내용을 [④ ______]을 기반으로 예측하여 답변을 만듭니다.

**제시 카드 — 8개**

{패턴} · {생성} · {문맥} · {확률} · {복사} · {검색} · {파일} · {명령어}

**정답 — 빈칸 순서**: ① 패턴 / ② 생성 / ③ 문맥 / ④ 확률

**오답 카드 — 4개**: 복사 / 검색 / 파일 / 명령어

**완성 문장**

> 생성형 AI는 학습한 패턴을 바탕으로 새로운 내용을 생성합니다.  앞서 나온 내용의 문맥을 고려하고, 다음에 올 내용을 확률을 기반으로 예측하여 답변을 만듭니다.

**고디의 힌트**: “AI가 많은 글에서 배운 표현을 활용해, 앞의 말에 어울리는 다음 말을 이어간다고 생각해봐. 어떤 말이 이어질 가능성이 있는지도 따져보는 거야!”

**문제 4 — 후보 B**

**제시 카드 — 6개**

{생성} · {고정된 정답} · {확률} · {검색} · {문맥} · {글자 수}

**정답 — 빈칸 순서**: ① 문맥 / ② 확률 / ③ 생성

**오답 카드 — 3개**: 고정된 정답 / 검색 / 글자 수

**완성 문장**

> 글을 만드는 생성형 AI는 질문과 앞선 문장의 문맥을 참고합니다. 학습한 언어의 패턴을 바탕으로 다음에 올 표현의 가능성을 확률로 계산하며, 이 과정을 반복해 답변을 생성합니다.

**고디의 힌트**: “먼저 질문과 앞의 말의 흐름을 살펴봐. 그 흐름에서 다음에 어떤 말이 이어질 가능성이 있는지 생각하면 돼!”

#### 구분 3 — AI의 답변은 항상 정확할까?

**문제 5 — 후보 A**

> 생성형 AI는 자연스러운 문장을 만들지만, 답변의 [① ______]을 항상 보장하지는 않습니다. 실제로 존재하지 않는 사실을 [② ______] 만들어 내는 현상을 [③ ______]이라고 합니다. 따라서 AI가 만든 내용은 중요한 업무에 활용하기 전에 [④ ______]해야 합니다.

**제시 카드 — 8개**

{정확성} · {그럴듯하게} · {할루시네이션(환각)} · {검증} · {속도} · {검색하여} · {기계학습} · {저장}

**정답 — 빈칸 순서**: ① 정확성 / ② 그럴듯하게 / ③ 할루시네이션 / ④ 검증

**오답 카드 — 4개**: 속도 / 검색하여 / 기계학습 / 저장

**완성 문장**

> 생성형 AI는 자연스러운 문장을 만들지만, 답변의 정확성을 항상 보장하지는 않습니다. 실제로 존재하지 않는 사실을 그럴듯하게 만들어 내는 현상을 할루시네이션이라고 합니다. 따라서 AI가 만든 내용은 중요한 업무에 활용하기 전에 검증해야 합니다.

**고디의 힌트**: “술술 읽히는 답변에도 실제로 없는 내용이 섞일 수 있어. 중요한 업무에 쓰기 전에 어떤 확인이 필요할까?”

## 1-4 — LLM 대화의 요령

### 참고용 — 매뉴얼에서 정리한 대화 요령 8가지

아래 내용은 제작자용 참고 자료다. 사용자 제공 매뉴얼의 내용을 교육용 표현으로 정리한 것으로, 학습자에게 여덟 항목을 한꺼번에 설명하거나 모두 출제하지 않는다.

| 요령 | 알려줄 내용 |
| --- | --- |
| 1. 목적과 상황을 구체적으로 말하기 | 무엇을 하려는지, 누가 읽거나 사용할지, 어떤 상황인지 알려 준다. 작업에 필요한 목적·대상·상황이 요청에 드러나도록 한다. |
| 2. 원하는 답의 모양 정하기 | 표·목록·세 줄 요약처럼 형식과 분량을 지정하고, 반드시 포함할 항목을 함께 알려 준다. |
| 3. 질문에 필요한 자료 고르기 | 이번 작업에 필요한 자료를 선택하고 어떤 자료를 기준으로 답할지 알려 준다. 다른 업무의 자료나 옛 예시가 섞이지 않도록 자료의 내용·시점·용도를 확인한다. |
| 4. 큰 작업은 순서대로 진행하기 | 먼저 자료를 요약하고 그 내용을 바탕으로 구체적인 분석이나 문서 작성을 요청하는 등, 앞선 결과를 다음 작업에 활용한다. 모든 질문에 계획 수립을 의무화하는 규칙으로 설명하지 않는다. |
| 5. 부족한 부분을 구체적으로 보완 요청하기 | “다시 해 줘”보다 “담당자와 기한을 추가해 줘”, “같은 내용을 표로 정리해 줘”처럼 바꿀 부분을 말한다. 관련 작업은 같은 대화에서 이어갈 수 있다. |
| 6. 모르는 내용은 구분해 달라고 하기 | 자료에 없는 내용을 임의로 채우지 않도록 요청한다. 근거가 없거나 추가 확인이 필요한 부분은 ‘확인 필요’로 표시하게 한다. |
| 7. 질문을 만드는 데도 AI의 도움 받기 | 어떻게 물어볼지 막히면 “이 질문을 더 구체적으로 고쳐 줘”라고 요청한다. 빠뜨린 조건을 찾거나 요청문을 다듬는 데 활용한다. |
| 8. 답변은 근거와 대조해서 확인하기 | 출처 표시를 열어 실제 원문을 확인한다. 날짜·금액·이름·인용 등이 맞는지 살피고, 수정된 내용도 근거와 비교한다. 최종 판단은 사람이 한다. |

| 항목 | 방식 |
| --- | --- |
| 중심 활동 | 나래가 AI에게 보낼 요청을 고디와 학습자가 함께 보완 |
| 화면·조작 | 상황·대화, 작성 중인 요청문, 번호 없는 선택 카드 4장, 선택 강조, 결과보기·해설, 근거 보기 |
| 순서 | 요청 조건 보완 → 참고 자료 선택 후 안내문 작성 → 검토·수정 요청 보완 → 원문 확인 |

### 공통 화면과 카드 선택 방식

- 카드에는 문구 또는 자료 제목·미리보기만 보여 준다. 학습자 화면에 선택지 번호나 A/B 같은 기호를 붙이지 않는다.
- 카드를 클릭하면 선택 상태가 강조되고, 다시 클릭하면 선택이 해제된다. 카드는 제자리에 있으며 드래그하거나 빈칸으로 옮기지 않는다.
- 문항마다 카드 두 장을 선택한 뒤 ‘결과보기’를 누른다. 선택한 카드의 문구가 나래의 요청문 아래에 붙어 강조된다. 선택을 해제하면 추가된 문구도 미리보기에서 빠진다.
- 자료를 고르는 문제에서는 선택한 자료가 요청창의 첨부 목록에 표시되고, 해당 자료를 참고하는 조건이 요청문에 추가되어 강조된다.
- 결과보기 뒤에는 선택의 정오, 정답 카드로 보완한 최종 요청문과 나래의 해설을 보여 준다. 다음 장면은 이 최종 예시를 기준으로 이어 간다.
- 아래 ‘제작자용 정답’, 보완된 요청문과 해설은 문제를 풀기 전에는 노출하지 않는다. 아래 표의 한 행이 카드 한 장이다.
- 첫 안내문은 문제 2에서 요청 조건과 참고 자료를 준비한 뒤 보여 준다. 문제 3은 오류 위치를 직접 찾게 하는 활동이 아니라, 검토·수정에 필요한 조건을 요청에 담고 실제 확인 과정을 살펴보는 활동이다.

### 도입

나래, 고디, 나는 스테이지 1-4에 도착한다.

- 나래: “이번에는 AI에게 축제 안내문을 부탁해 볼게요. 제가 요청하는 모습을 보면서, 놓친 부분이 있다면 함께 채워주세요!”
- 고디: “좋아! 어떤 정보를 알려줘야 할지 같이 살펴보자!”

다음 버튼을 누르면 첫 번째 문제로 이동한다.

### 문제 1 — 요청에서 빠진 조건 찾기

## 1-5 — AI로 해결하기 적합한 문제

### 학습 목표와 진행 형태

월드 1의 도입 단계로, AI의 도움을 받을 수 있는 구체적인 활용 장면 두 가지를 소개한다.

- 문항 1: 여러 사람이 쓴 후기에서 비슷한 의견을 묶고 주요 내용을 정리하기.
- 문항 2: 원하는 장면과 분위기를 설명해 이미지 초안을 만드는 활용과 편리함 알아보기.

**유형: 클릭형 상황·방법 카드 선택 + 주관식(사내 GPT 1회 평가) + 나래의 활용 활용 예시·해설**

| 항목 | 방식 |
| --- | --- |
| 중심 활동 | 활용 장면을 고르고, 안내에 따라 공통 AI 활용 상황에서 편리해지는 점을 설명 |
| 화면·조작 | 제목·설명이 있는 카드 2장, 선택별 나래 안내, 이유 입력란, 평가 피드백, 고정 활용 예시·해설, 다음 이동 |
| 순서 | 카드 선택 → 선택별 “좋아요!” 안내 → 공통 B 질문에 답변 1회 → API 평가·피드백 → 나래의 활용 예시·해설 → 다음 문항 |
| 제출 | 문항별 최초 선택과 B에 대한 주관식 답변. 최초 선택은 기록·안내 분기용이며 채점하지 않음 |
| AI 사용 | 사내 GPT API로 주관식만 평가할 예정. 문항 1의 후기·요청·정리 결과와 문항 2의 요청문 예시는 사전 준비 자료 사용. 문항 2에서 실제 이미지를 생성하거나 표시하지 않음 |
| 문항 수 | 2문항을 순서대로 진행하며, 문항마다 주관식 제출은 1회 |

실제 게임 화면·API 연동 구현은 이번 문서 반영과 구분한다. 문항 2는 요청문 예시와 해설 텍스트로 진행하며 실제 이미지 제작이나 표시를 요구하지 않는다. API 호출과 채점 일관성, 브라우저 동작은 아직 검증하지 않았다.

### 공통 선택·답변·피드백 규칙

- 카드에는 제목과 설명을 표시하며, 선택지 번호와 A/B 기호는 학습자 화면에 보여 주지 않는다. 아래 A/B는 제작자·채점자용 식별자다.
- 두 카드 중 한 장을 클릭한다. 최초 선택 자체에는 정답·오답 표시를 하지 않는다.
- 어느 카드를 골라도 나래는 “좋아요!”라고 반응하고, 각 문항의 공통 B 질문으로 연결한다.
- 최초 선택을 고른 이유부터 쓰게 하지 않는다. A/B 안내가 끝난 뒤 B의 AI 활용에 대한 답변을 한 번만 받는다.
- 주관식 안내는 “생각한 내용을 자유롭게 적어 주세요. 짧게 적어도 괜찮아요.”로 통일한다. 답변하는 내용의 개수는 제한하지 않는다.
- 최초 선택이 A이고 주관식 답변이 B에 관한 것이어도 정상 흐름이다. 선택과 이유의 불일치로 감점하거나 내부 재검토 표시를 하지 않는다.
- 평가 후에는 잘 설명한 점 또는 보완할 점을 짧게 보여 주고, 나래의 활용 예시와 공통 해설을 이어서 보여 준다.
- 문항별 판정과 내부 재검토 여부에 관계없이 활용 예시·해설 확인 후 다음으로 진행한다. 재작성·재제출·재채점을 요구하지 않는다.
- 평가 판정과 풀이 완료를 구분한다. 두 문항의 피드백·활용 예시·해설을 확인하면 1-5 풀이 완료이며, 문항 2 뒤에는 월드 엔딩으로 연결한다.
- 아래 제작자용 채점 기준·답변 예시는 제출 전에 노출하지 않는다.

### 도입

나래, 고디, 나는 스테이지 1-5에 도착한다.

- 나래: “이제 AI를 어떤 일에 활용할 수 있는지 살펴볼게요. 두 가지 장면을 보면서, AI의 도움을 받으면 어떤 점이 편해질지 생각해 봐요!”
- 고디: “우리가 앞으로 할 축제 업무에서도 활용할 수 있겠네!”
- 나래: “먼저 카드를 골라 주세요. 그다음 제가 안내하는 AI 활용 장면에서 어떤 점이 편해질지 자유롭게 적어 주시면 돼요. 답변 뒤에는 다우리 GPT의 피드백과 활용 예시를 함께 살펴볼게요!”

다음 버튼을 누르면 문항 1로 이동한다.

### 문항 1 — 여러 후기를 정리할 때 AI 활용하기

**문항 ID: 1-5-01**

나래가 축제 업무 두 가지를 보여 준다.

| 제작자용 식별자 | 화면에 보여 줄 카드 제목 | 카드 설명 |
| --- | --- | --- |
| A | 판매 수량 합계 구하기 | 판매 수량이 엑셀 표에 정리되어 있어요. 기존 합계 수식으로 총수량을 바로 계산할 수 있습니다. |
| B | 방문객 후기 정리하기 | 여러 사람의 후기가 자유로운 글로 모여 있어요. 표현이 달라도 비슷한 의견끼리 묶어 주요 불편 사항을 파악하려고 합니다. |

**카드 선택 질문**

> 어떤 업무에서 AI의 도움을 받아보고 싶나요? 상황 카드를 골라 주세요.

**A를 선택했을 때**

- 나래: “좋아요! 계산 방법이나 수식에 관해 AI의 도움을 받을 수도 있죠. 이번에는 방문객 후기 정리에서도 AI를 활용해 볼까요?”

**B를 선택했을 때**

- 나래: “좋아요! 방문객 후기 정리에서도 AI의 도움을 받을 수 있어요. AI를 활용하면 어떤 점이 편해질지 생각해 봐요!”

**공통 주관식 질문**

> 방문객 후기를 정리할 때 AI를 활용하면 어떤 점이 편해질까요? 생각한 내용을 자유롭게 적어 주세요.

입력란 아래에 “짧게 적어도 괜찮아요.”를 표시한다. 작성 후 ‘답변 제출’을 누르면 이 답변을 한 번 평가한다. 최초 선택이 A여도 위 질문은 B에 대한 질문이며, 추가 답변이나 재답변이 아니다.

**평가 후 시연 — 원래 후기 → 나래의 요청 → AI의 정리 결과**

나래가 후기 일부를 보여 준다.

> “줄을 오래 섰어요.”\
> “입장 대기가 길었어요.”\
> “예약 방법을 찾기 어려웠어요.”

이어서 나래의 요청을 보여 준다.

> 비슷한 의견끼리 묶고, 주요 불편 사항을 정리해 줘.

화면에 AI가 정리한 고정 예시를 보여 준다.

| 묶은 주제 | 핵심 의견 |
| --- | --- |
| 입장 대기 | 기다리는 시간이 길었다는 의견 |
| 체험 예약 안내 | 예약 방법을 찾기 어려웠다는 의견 |

- 나래: “표현이 달라도 비슷한 내용을 모아서 정리할 수 있어요. 이렇게 여러 글에서 필요한 내용을 추리고 정리할 때 AI의 도움을 받을 수 있답니다. 정리된 의견을 보면 다음 축제에서 개선할 부분도 살펴보기 편해지겠죠?”
- 고디: “글이 여러 개여도 어떤 의견이 나왔는지 모아서 볼 수 있겠네!”

이 시연은 이해를 돕는 예시다. 정리 결과를 분석하는 추가 주관식 질문은 하지 않는다.

‘다음 문제’를 누르면 문항 2로 이동한다.

### 문항 2 — 축제 포스터 배경 그림 제작에 AI 활용하기

**문항 ID: 1-5-02**

이번에는 같은 결과물을 만드는 두 가지 작업 방식을 보여 준다.

**상황**

가족이 함께 즐기는 봄 축제 포스터를 만들려고 한다. 꽃이 핀 광장에서 사람들이 축제를 즐기는 배경 그림이 필요하다.

| 제작자용 식별자 | 화면에 보여 줄 카드 제목 | 카드 설명 |
| --- | --- | --- |
| A | 직접 제작하기 | 필요한 그림을 찾거나 직접 그린 뒤, 디자인 도구로 배경 시안을 구성한다. |
| B | AI 활용하기 | 원하는 장면과 분위기를 설명해 배경 그림의 시안을 생성한다. |

**카드 선택 질문**

> 어떤 방법으로 배경 그림의 시안을 만들어 보고 싶나요? 방법 카드를 골라 주세요.

**A를 선택했을 때**

- 나래: “좋아요! 직접 그림을 찾거나 그리면서 원하는 모습으로 시안을 구성할 수 있죠. 이번에는 AI로 시안을 만드는 방법에서도 어떤 도움을 받을 수 있을지 살펴봐요!”

**B를 선택했을 때**

- 나래: “좋아요! 원하는 모습을 설명해서 이미지 시안을 만들어 볼 수 있어요. AI를 활용하면 어떤 점이 편해질지 생각해 봐요!”

**공통 주관식 질문**

> 포스터 배경 그림의 시안을 만들 때 AI를 활용하면 어떤 점이 편해질까요? 생각한 내용을 자유롭게 적어 주세요.

입력란 아래에 “짧게 적어도 괜찮아요.”를 표시한다. 작성 후 ‘답변 제출’을 누르면 이 답변을 한 번 평가한다. 처음에 직접 제작하기를 선택했어도 B의 AI 활용에 대한 답변만 평가한다.

**평가 후 해설 — 이미지 생성 요청문 예시와 활용 설명**

나래가 AI에게 요청할 수 있는 예시를 텍스트로 보여 준다. 이 요청을 실제로 실행하거나 생성된 이미지를 화면에 표시하지 않는다.

> 꽃이 핀 광장에서 가족들이 봄 축제를 즐기는 배경 그림을 만들어 줘. 밝고 따뜻한 분위기로, 글자는 넣지 말아 줘.

- 나래: “원하는 모습을 말로 설명해서 이미지의 초안을 만들어 볼 수 있어요. 직접 그림을 처음부터 구성하는 부담을 줄이고, 여러 방향의 시안을 시도해 볼 수도 있죠. 이후 행사명과 일정 같은 안내 정보를 배치해 포스터를 완성할 수 있답니다!”
- 고디: “어떤 그림을 원하는지 설명해서 이미지 초안을 만들어 볼 수 있겠네!”

문항 2의 해설은 요청문 예시와 나래·고디의 대사로만 진행한다. 실제 이미지나 이미지 자리표시자를 배치하지 않고, 이미지 비교·선택 활동이나 추가 주관식 답변도 요구하지 않는다.

‘해설 확인’을 누르면 1-5 마무리로 이동한다.

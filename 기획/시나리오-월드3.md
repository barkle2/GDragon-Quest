# 월드 3 상세 시나리오 — 진실의 기록관

[전체 시나리오](시나리오.md) · [등장인물](등장인물.md) · [수행형 활동과 검토](수행형활동과검토.md)

## 목표·이야기·공통 방식

승인한 방향은 검증할 주장·근거를 직접 찾아 수정·보류하는 활동입니다. 자료·대사·평가·지역명은 검토 초안이며 실제 지침·법령이 아닌 가상 사건입니다. 실제 내부 규정과 자료 이용 기준 반영은 미정입니다.

서온(올빼미 기록관장), 두리(거북 집계 담당), 온유(얼굴 없는 갑옷)가 지역 보고 초안을 검토합니다. 고드래곤은 답 위치를 먼저 알려주지 않고 필요할 때 단서를 제공합니다. 부탁→짧은 설명·예제→검토 작업→수정본·검토 기록→후속 부탁→완료로 진행합니다. 도움·완료·API 예외·검증 한계는 공통 수행형 문서를 따릅니다. 첫 시제품 범위는 월드 1입니다.

## 3-1 — 주장과 근거 연결하기

**유형: 자료 비교형·근거 연결형** / 보조: 문서 편집형·서술형

### 진행 형태

| 항목 | 방식 초안 |
| --- | --- |
| 중심 활동 | 주장 추출·근거 연결·검토 기록·보고 편집 |
| 화면·조작 | 초안의 문장 선택, 근거 문서·항목 연결, 상태·이유 입력 |
| 순서 | 확인할 주장 선정 → 근거 대조 → 상태·이유 → 수정본 → 새 공지 반영 |
| 제출 | 주장별 검토 기록·근거·수정본 |
| AI 사용 | 주장 추출 보조 선택 가능, 출력은 사용자 검토 |

**목표**: 오류가 표시되지 않은 보고에서 검증할 주장을 추출하고 자료에 연결합니다.

- 서온: “어디부터 확인해야 할지도 정해 주세요.” 고드래곤: “주장마다 무엇을 근거로 말하는지 찾아봐요.”
- 설명문: “자료에 없는 내용과 자료에 어긋나는 내용을 구분합니다.” 예제는 본 문제와 다른 한 문장의 근거 연결만 보여줍니다.
- 자료 서랍: 북쪽 다리 점검 기록(점검 중·개통 미정), 지난 남쪽 다리 개통 공지, 출처 없는 주민 소문, 현재 북쪽 다리 위치도.
- 초안: 북쪽 다리 완공, 달맞이날 개통, 왕국 최초 돌다리, 북쪽 지역 위치. 오류 수·위치는 먼저 알려주지 않습니다.

**수행·화면**: 초안에서 확인할 문장을 선택해 주장 목록을 만들고 근거 문서·항목을 연결합니다. ‘확인됨/불일치/확인 불가’ 상태와 짧은 이유를 작성합니다. AI에게 주장 추출을 요청할 수 있지만 제안 목록을 직접 점검합니다. 수정본을 편집합니다.

**산출물·완료 후보**: 주장별 근거·상태, 수정본. 점검 중·개통 미정으로 고치고 최초 주장은 삭제 또는 확인 대기. 위치는 자료가 맞으면 유지합니다. 모든 문장을 오류로 처리하지 않습니다.

**후속 부탁**: 새 확정 공지 ‘개통일 별맞이날’ 추가. 기존 검토 중 날짜 항목만 갱신하고 새 근거·이유를 남깁니다. 다른 항목까지 확인된 것으로 바꾸지 않습니다.

힌트 “문서의 지역과 시점도 비교해요.” 수정 “남쪽 다리 자료가 북쪽의 근거가 될까요?” 완료: 서온 “확인된 것과 더 물을 것을 나누었군요.”

## 3-2 — 숫자 검토 기록 만들기

**유형: 계산 입력형** / 보조: 문서 편집형·근거 연결형

### 진행 형태

| 항목 | 방식 초안 |
| --- | --- |
| 중심 활동 | 직접 계산·범위 판단·검토 보고 편집 |
| 화면·조작 | 원자료·계산식 입력·계산 결과·수정 문장·근거 연결 |
| 순서 | 검토 항목 정의 → 합계·분모 계산 → 표현 수정 → 새 지역 추가 계산 |
| 제출 | 식·결과·범위 이유·갱신 보고 |
| AI 사용 | 계산식 제안은 선택. 산술은 별도 계산 도구로 확인 |

**목표**: 계산 근거·분모·자료 범위를 직접 확인하고 보고를 고칩니다.

- 두리: “참여율 계산과 설명이 맞는지 검토 기록을 남겨 주세요.”
- 설명문: “계산값뿐 아니라 무엇을 나누었는지·어디까지 설명할 수 있는지 봅니다.” 예제는 대상10·참여5의 비율만 설명합니다.
- 자료: 동쪽 대상20·참여10, 서쪽 대상30·참여20. 다른 지역 자료 없음. 초안 ‘왕국 전체 참여율100%’. 계산기 화면은 정확한 산술용 별도 도구 후보입니다.

**수행**: 사용자가 검토 항목을 적고 합계·계산식을 직접 입력해 계산 도구로 확인합니다. AI가 제안한 식을 사용할 수도 있지만 자료와 대조합니다. 수치·표현을 편집하고 범위 제한 이유를 남깁니다.

**산출물·완료 후보**: 대상50·참여30·30/50=60%, 두 지역이라는 범위가 담긴 수정본과 원자료 연결. 숫자만60으로 바꾸고 왕국 전체를 유지하면 보완합니다.

**후속 부탁**: 남쪽 대상10·참여0을 추가해 총대상60·참여30·세 지역50%로 갱신합니다. 미접수 지역은 0으로 처리하지 않고 별도 상태로 구분하는 변형 후보입니다.

힌트 “분모와 빠진 지역을 보세요.” 수정 “새 지역을 더하면 기준도 바뀝니다.” 완료: 두리 “어떻게 계산했는지 따라갈 수 있네요.”

## 3-3 — 사용할 자료 준비하기

**유형: 자료 선택형** / 보조: 서술형(판단이유·확인 요청)

### 진행 형태

| 항목 | 방식 초안 |
| --- | --- |
| 중심 활동 | 자료 이용 조건 검토·자료 묶음/확인 요청 작성 |
| 화면·조작 | 규칙·자료 서랍·선택 묶음·판단 이유·확인 요청 입력 |
| 순서 | 조건 대조 → 제외/보류 이유 → 허용 묶음 또는 확인 요청 → 새 공개 여부 반영 |
| 제출 | 사용할 자료·제외 이유 또는 구체적인 확인 요청 |
| AI 사용 | 금지·미확인 자료를 실제 전송하지 않는 가상 활동 |

**목표**: 명시된 이용 조건에 맞게 사용할 자료를 준비하거나 사용을 보류합니다.

- 온유: “자료를 읽는 것과 도구에 입력하는 것은 구분합니다.”
- 가상 규칙: 공개 안내문만 연습 도구에 입력 가능, 식별 정보·비공개 기록은 불가, 공개 여부 불명확하면 담당자 확인.
- 자료: 공개 장터 시간표, 주민 이름·주소·개인 사정 기록, 공개 여부 미확인 회의 메모. 모두 게임의 가상 자료이며 금지 항목 실제 전송 기능은 제공하지 않습니다.
- 설명문: “이름 삭제만으로 허용 조건을 만족한다고 판단하지 않습니다.” 예제는 허용 공개 안내문을 보여줍니다.

**수행**: 자료별 판단과 이유를 남기고 AI에 전달할 ‘사용 자료 묶음’을 구성합니다. 공개 문서만 사용하는 안 또는 모두 보류하고 확인 요청하는 안을 만들 수 있습니다. 확인 요청에는 무엇의 공개 여부·허용 조건을 물을지 작성합니다. 원문 임의 익명화로 입력 허용을 확정하지 않습니다.

**산출물·완료 후보**: 허용된 자료 묶음 또는 구체적인 확인 요청, 제외한 이유. 규칙에 어긋나는 자료가 포함되면 전송 전에 수정 안내합니다.

**후속 부탁**: 회의 메모가 비공개라는 답을 제공해 묶음·검토 기록을 갱신합니다. 원본 대신 공개 대체 자료가 주어지면 따로 검토해 추가합니다.

힌트 “어떤 내용보다 어떤 허용 조건인지도 보세요.” 수정 “이름을 지워도 비공개 조건은 남아요.” 완료: 온유 “확인 전에 멈추고 대안을 준비했군요.”

## 3-4 — 판단 기준 다시 세우기

**유형: 서술형(기준표·추천 의견)** / 보조: 질문 선택형 대화·오류 표시형

### 진행 형태

| 항목 | 방식 초안 |
| --- | --- |
| 중심 활동 | 정보 질문·판단 기준표·추천 의견 작성 |
| 화면·조작 | 문제 표현 표시·질문 카드·기준표·의견 편집 |
| 순서 | 근거 부족 식별 → 필요한 정보 확인 → 기준·추천안 → 역할 변경 후 재검토 |
| 제출 | 기준·근거·추천/보완 의견·변경 대응 |
| AI 사용 | 검토 관점 보조 후보, 최종 판단 대신하지 않음 |

**목표**: 근거 없는 일반화를 찾아 필요한 정보를 수집하고 기준을 수정합니다.

- 서온: “추천안은 올빼미만 기록 담당에 적합하다고 합니다.” 고드래곤: “맡을 일과 직접 연결되는 근거를 보죠.”
- 역할 기준: 기록 비교 정확성·출처 표시·참여 가능 시간. 후보별 실제 정보는 질문 카드에서 확인합니다.
- 질문 답 자료: 후보A 정확성90%·출처 표시 있음·시간 가능, B95%·출처 누락·시간 가능, C90%·출처 있음·시간 불가. 인간·토끼·올빼미로 배정하는 후보이며 종족이 점수의 원인이라는 설명은 하지 않습니다.
- 설명·예제: 종족만으로 단정한 표현을 기준 기반 질문으로 바꾸는 예시.

**수행**: 문제 표현을 직접 표시하고 추가 정보 주제를 선택합니다. 필요한 기준표를 작성한 뒤 추천안과 보완 의견을 직접 씁니다. AI에게 검토 관점을 요청할 수 있지만 출력 그대로 최종결정하지 않습니다.

**산출물·완료 후보**: 역할 관련 기준·근거·보완 의견. A추천은 허용 예시이며 B의 출처 보완 후 검토 등 조건부 대안도 인정합니다. 종족만으로 배제하는 판단은 수정합니다.

**후속 부탁**: 역할이 기록 비교에서 방문객 안내로 바뀝니다. 기존 숫자만으로 새 역할을 추천하지 않고 필요한 안내 능력·시간 정보를 질문합니다. 정보 부족을 인정한 확인 계획도 결과입니다.

힌트 “일이 바뀌면 기준도 달라질까요?” 완료: 서온 “역할과 근거에 맞춰 검토했네요.”

## 3-5 — 검토한 보고서 전달하기

**유형: 자료 비교형·문서 편집형** / 보조: 계산 입력형·근거 연결형·서술형

### 진행 형태

| 항목 | 방식 초안 |
| --- | --- |
| 중심 활동 | 독립 검토 계획·근거 대조·수정/보류 보고 |
| 화면·조작 | 검토 목록·자료·주장 연결·계산·보고 편집 |
| 순서 | 점검 계획 → 주장·조건 대조 → 수치 확인 → 수정/확인 요청 → 새 확정 자료 갱신 |
| 제출 | 검토 기록·수정본·확인 대기 상태 |
| AI 사용 | 검토 제안은 선택 보조, 근거는 별도 확인 |

**목표**: 도움을 줄인 새 보고에서 검증 계획·근거·조치를 종합 수행합니다.

- 온유: “다음 보고는 확인 위치를 표시하지 않았습니다.” 고드래곤: “어떤 순서로 살필지 직접 정해요.”
- 자료: 도서관 운영 별맞이날 오후3시·무료·예약 미정, 동쪽 방문8/대상10·서쪽12/20, 공개 운영표만 입력 허용. 초안은 오후4시·예약필수·왕국전체 방문율100%·비공개 기록 입력 제안.
- 설명문: “확인할 주장과 입력 조건을 먼저 정합니다.” 완성 답안을 사전에 보여주지 않습니다.

**수행**: 검토 목록 작성→자료 선택→주장·근거 연결→수치 계산→수정본과 확인 요청 작성. AI 검토 제안은 선택 보조이며 누락·허위 근거를 사용자도 확인합니다.

**산출물·완료 후보**: 오후3시·무료 유지·예약 확인 대기, 두 지역20/30 약66.7%(반올림 규칙 후보), 비공개 입력 보류가 담긴 보고와 검토 기록. 확인된 항목만 전달 또는 전체 보류 모두 조건과 상태가 일치하면 허용합니다.

**후속 부탁**: 예약 불필요 확정 자료를 받아 관련 문장·근거만 갱신합니다. 보류 상태가 바뀌는 이유도 기록합니다.

힌트는 요청 시 점검 범주만 제공합니다. 완료: 서온 “결론뿐 아니라 확인한 근거를 함께 전달했군요.” 항구도시로 연결합니다.

## 남은 검토

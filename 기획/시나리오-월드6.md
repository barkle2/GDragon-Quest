# 월드 6 상세 시나리오 — 왕국의 미래 회의

[전체 시나리오](시나리오.md) · [등장인물](등장인물.md) · [수행형 활동과 검토](수행형활동과검토.md)

## 목표·이야기·공통 방식

승인한 방향은 여러 타당한 대안을 비교해 자신의 계획과 선택 근거를 만들고 제약 변화에 대응하는 것입니다. 구체적 수치·자료·판정·지역명·대사는 검토 초안입니다. 실제 혁신 실행·법적 정책 판단·공식 이수 인증은 범위가 아닙니다.

아델(사자 운영 책임자), 로안(인간 예산 담당), 미르(염소 주민 대표)와 이전 지역의 해루·율·서온·리아가 대사 순서로 등장합니다. 한 화면1~2명, 자유 이동·전투 없음. 주민의 질문에 계획 문서·비교표를 수정하는 진행입니다.

공통 수행형 기준을 따르며 결과물·이유·변경 대응을 확인합니다. 예시 답을 복사하거나 모든 체크를 누르는 것으로 완료시키지 않습니다. 재도전·힌트 불이익·시간 제한·별도 시험은 추가하지 않습니다. API·의미 검증·저장·보상은 미정입니다.

## 6-1 — 어디부터 시작할지 제안하기

**유형: 비교표 작성·서술형** / 보조: 질문 선택형 대화·자료 선택형

### 진행 형태

| 항목 | 방식 초안 |
| --- | --- |
| 중심 활동 | 정보 질문·후보 비교·시범 제안 작성 |
| 화면·조작 | 자료 서랍·질문·비교표·제안 편집 |
| 순서 | 정보 보완 → 후보 비교 → 범위·이유 → 담당자 부재 대응 |
| 제출 | 비교표·시범안·근거·변경안 |
| AI 사용 | 쟁점 정리 보조, 자료로 결과 확인 |

**목표**: 자료를 보완해 도입 후보와 범위를 스스로 정합니다.

- 아델: “지역마다 필요한 도움이 달라요. 먼저 시도할 일과 이유를 제안해 주세요.”
- 자료 서랍: 공개 안내문 초안(반복 부담·검토 담당 있음), 공개 주문 메모 표 추출(집계 확인 담당 있음), 정형 합계(계산 도구로 가능). 예상시간·누락비율은 가상 기준선 자료로 제공합니다. 모호한 비용·자료 허용은 질문 카드로 확인합니다.
- 설명문: “효과·자료 준비·확인 여건·위험과 비용을 함께 봅니다.” 예제는 비교 항목 한 개만 보여줍니다.

**수행**: 필요 질문을 선택하고 후보 비교표를 직접 씁니다. AI에 쟁점 정리를 요청할 수 있으나 자료에 없는 장점을 검증합니다. 첫 시범 후보·범위·남길 과제의 근거를 작성합니다.

**산출물·검토**: 후보 비교·시범 제안·근거. 안내문 또는 주문 표 등 조건을 충족한 서로 다른 선택을 허용합니다. 일반 계산 개선을 우선하는 제안도 이유가 타당하면 허용 후보입니다.

**후속 부탁**: 선택한 업무의 검토 담당이 당분간 부재라는 자료를 줍니다. 대체 확인 인력 확보·범위 축소·다른 후보·시범 보류 중 하나를 근거로 제안합니다.

힌트 “효과뿐 아니라 확인할 사람도 준비됐나요?” 완료: 아델 “무엇부터 왜 시작할지 이해할 수 있네요.”

## 6-2 — 개선 흐름과 역할 설명하기

**유형: 흐름 구성·실행형** / 보조: 서술형(역할·효과 설명)

### 진행 형태

| 항목 | 방식 초안 |
| --- | --- |
| 중심 활동 | 병목 분석·전후 흐름·시험·효과 설명 |
| 화면·조작 | 관찰 자료·흐름 편집·사례 시험·설명 입력 |
| 순서 | 문제·근거 → 역할/흐름 → 시험 → 효과 확인 계획 → 새 필드 대응 |
| 제출 | 전후 흐름·역할·시험·예상효과의 근거 |
| AI 사용 | 초안 지원 후보, 흐름 실행기는 미구현 |

**목표**: 병목 자료를 분석하고 개선 흐름을 직접 그려 설명합니다.

- 해루: “어디서 시간이 걸리는지 자료를 보고 바꿔주세요.”
- 자료: 접수5분·중복 재입력10분·초안8분·검토7분. 담당자 관찰에는 재입력 누락과 검토 중 수정도 포함. 합계30분은 가상 기준선이며 개선안의 실제 성과를 뜻하지 않습니다.
- 설명문: “병목을 파악한 뒤 입력·도구·사람의 역할을 바꿉니다.” 예제는 관찰과 제안의 구분입니다.

**수행**: 자료에서 문제·근거를 추출하고 현재/개선 흐름을 작성합니다. AI 초안·구조화 입력·계산·담당 검토를 적절히 배치하고 월드5 방식으로 사례 입력을 시험합니다.

**산출물·검토**: 전후 흐름·역할·시험 결과·예상효과와 확인방법. 검토 시간이 줄었다고 측정 없이 확정하지 않습니다. 서로 다른 흐름도 허용합니다.

**후속 부탁**: 자료에 새로운 예외 필드가 추가됩니다. 입력 확인과 담당자 경로를 수정하고 예상 부담을 다시 설명합니다.

힌트 “남겨야 할 확인을 없애진 않았나요?” 완료: 해루 “역할과 책임이 보이는 계획이 됐어요.”

## 6-3 — 타당한 대안 사이에서 선택하기

**유형: 비교표 작성·서술형** / 보조: 질문 선택형 대화

### 진행 형태

| 항목 | 방식 초안 |
| --- | --- |
| 중심 활동 | 장단점 비교·선택 이유·제약 변경 대응 |
| 화면·조작 | 대안 자료·주민 질문·비교표·근거/한계 입력 |
| 순서 | 우선순위 확인 → 수치 비교 → 선택·한계 설명 → 예산 변경·수정 |
| 제출 | 비교표·선택안·감수할 한계·변경 이유 |
| AI 사용 | 비교 제안 보조, 단일 최적안 자동 확정하지 않음 |

**목표**: 모두 기본조건을 충족한 대안의 상충하는 장단점을 비교합니다.

- 로안: “어느 것도 완벽하지 않습니다. 이번 왕국에 맞는 이유를 설명해 주세요.”
- 가상 조건: 동일자료·담당자 검토·허용 확인을 모든 대안이 충족. A 비용8·총처리12분·수정필요3/20건, B 비용6·18분·1/20건, C 일반 처리 비용4·25분·1/20건. 값은 같은 시험 묶음의 가상 관찰이며 보편적 성능이 아닙니다.
- 초기 예산10, 시간·품질 우선순위는 주민 질문으로 확인합니다. 설명문: “필수조건을 만족한 뒤 비용·시간·수정 부담을 함께 비교합니다.”

**수행**: 직접 비교표·선택 이유·감수하는 한계를 작성합니다. AI 비교 제안을 자료와 대조하고 누락된 관점을 보완합니다.

**산출물·검토**: A/B/C 중 타당한 선택과 정확한 수치·한계·검토 계획. 단일 최적안을 강제하지 않습니다. A선택이면 수정 부담을 숨기지 않아야 합니다.

**후속 부탁**: 예산이5로 줄어 C만 현재 비용조건을 충족합니다. C로 전환·범위 축소 후 재견적·추가예산 확인 전 보류 등 근거 있는 대응을 작성합니다. A를 예산 안이라고 주장하면 수정합니다.

힌트 “새 제약을 비교표에 반영했나요?” 완료: 로안 “선택 이유와 비용 한계를 설명했군요.”

## 6-4 — 실행 가능한 시범 계획 만들기

**유형: 문서 작성·편집형** / 보조: 직접 입력 대화형(LLM)·근거 연결형

### 진행 형태

| 항목 | 방식 초안 |
| --- | --- |
| 중심 활동 | 계획 작성·근거 연결·가상 운영 결과 반영 |
| 화면·조작 | 제약 자료·계획 양식·AI 대화 후보·근거·결과 기록 |
| 순서 | 목표/범위/역할/지표/대응 작성 → 검토 → 가상 오류 결과 → 계획 수정 |
| 제출 | 계획·측정 방법·중단/재개 조건·수정안 |
| AI 사용 | 초안·검토 보조, 효과 수치를 측정 없이 보장하지 않음 |

**목표**: 목표·범위·역할·근거·지표·중단 대응이 있는 짧은 계획을 작성합니다.

- 아델: “작게 시작하고 결과를 확인할 계획을 써 주세요.” 미르: “사용이 어려운 주민도 도움받을 길이 있어야 해요.”
- 가상 제약: 공개 안내문10건·2주·담당 검토·비공개 자료 제외·예산10. 기준선 작성+검토30분/건, 오류수와 문의기록은 제공 사례에 포함.
- 설명문: “목표 수치는 희망과 관찰을 구분하고 측정방법을 함께 적습니다.” 예제는 한 지표의 측정방법입니다.

**수행**: 빈 계획 양식에 직접 작성하거나 AI 초안을 편집합니다. 목표·대상·역할·비용·수집할 결과·검토/중단 기준·주민 지원을 채우고 근거 자료를 연결합니다.

**산출물·검토**: 계획과 선택 근거. 사용횟수만으로 효과를 판단하지 않고 작성+검토시간·오류·문의 등 선택한 지표의 정의·측정 시점을 명시합니다. 근거 없는 절감률 약속을 요구하지 않습니다.

**후속 부탁**: 시범 중10건 평균총시간20분, 중대 오류1건이 실제 게시된 가상 결과를 줍니다. 시간개선(30→20분)만으로 성공 확정하지 않고 오류영향·정정·일시 보류/조건부 재개 방안을 계획에 반영합니다. 허용 정책과 재개 기준은 자료로 명시해야 합니다.

힌트 “시간이 줄어도 오류 영향은 어떤가요?” 완료: 미르 “성과와 문제에 대응할 방법이 함께 있네요.”

## 6-5 — 고드래곤과 왕국 계획 완성하기

**유형: 복합 수행형** / 보조: 직접 입력 대화형(LLM)·표/문서 편집형·흐름 실행형·서술형

### 진행 형태

| 항목 | 방식 초안 |
| --- | --- |
| 중심 활동 | 독립 종합 수행·보고·흐름 시험·대안/계획 수정 |
| 화면·조작 | 질문/자료·AI 대화·표/보고 편집·근거·흐름 시험·계획 |
| 순서 | 정보 수집 → 접수/초안 → 검증 → 흐름/대안 → 최종 보고/계획 → 추가 접수·정정·예산 변화 |
| 제출 | 접수표·보고·검토·흐름/시험·선택 근거·갱신 계획 |
| AI 사용 | 실제 지원과 일반 처리 조합 후보, 자유 산출물 판정은 미정 |

**목표**: 새 자료 묶음에서 문제 정의·산출물·검증·흐름·대안·변경 대응을 독립적으로 연결합니다.

- 아델: “지역 보고를 취합할 계획과 실제 전달할 결과를 준비해 주세요.”
- 고드래곤: “이번에는 순서를 직접 정해 봐요. 도움이 필요하면 함께 확인할게요.”
- 자료: 공개 보고 양식·대상10지역·8접수·2미접수·수량 빈칸1건, 일부 별도 상세자료 허용 미확인. 도구 기능·비용·담당자 제약은 질문·자료 서랍에서 제공합니다. 정확한 총수량은 자료 보완 전 확정 불가.
- 설명문: “현재 결과와 실행 계획을 구분하고 확인 대기를 정확히 알립니다.” 완성 계획은 미리 보여주지 않습니다.

**수행**: 필요한 자료·정보 확인→직접 AI 요청으로 접수표·보고 초안→원문·수치 검증→월드5 흐름 후보와 시험→대안 비교→최종 보고·운영 계획을 작성합니다. 모두 AI로 처리할 필요는 없습니다. 실제 정정·질문·근거·시험 결과를 연결합니다.

**산출물·검토**: 접수표·검토한 보고·흐름/시험 기록·선택 근거·운영 계획. 접수8/10·빈칸 확인 중·총수량 미확정을 유지하고 미허용 자료는 사용하지 않습니다. 확인된 공개 항목 공유와 전체 보류 모두 조건에 맞게 허용합니다.

**후속 부탁**: 나머지2지역 보고가 오되 기존지역 정정본이 함께 들어오고 예산이 줄어듭니다. 중복·정정 처리, 검토 상태·계획의 비용과 범위를 갱신합니다. 새 총수량은 실제 후속 자료 수치로 계산하며 명세 제작 단계에서 수치를 확정합니다.

**완료 판단 후보**: 사실·원문 대응·미정 상태·역할 책임·예외 처리·제약 준수·변경 이유를 함께 검토합니다. 자유 결과물의 검증 방법은 미정이며 체크나 단일 LLM 점수만으로 완료시키지 않습니다.

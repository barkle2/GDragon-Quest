## 목적과 현재 상태

전체 화면 시안과 실제 프로그램에 배치할 개별 자산을 구분합니다. 시안 PNG는 외형 참고용이며 버튼·대사·문제를 이미지에 포함한 채 프로그램 화면으로 사용하지 않습니다.

이번에는 공통 마을 배경 1개, 주민 5명의 기본 이미지, 제공된 고드래곤 원본 4개의 선별 사본을 준비했습니다. 그림체·주민 외형은 검토 후보입니다. 원본 폴더와 기존 시안은 보존했습니다.

### 주민 외형 후보

아래 목록은 현재 제작된 인간형 이미지의 외형입니다. [등장인물 목록](등장인물.md)에 수인·어린이·갑옷·골렘을 섞은 새 배정안을 제안했습니다. 특히 모아·보람·다온은 새 후보를 채택하면 재제작이 필요하며 현재 파일은 보존합니다.

나래·보람의 외형 유사성이 사용자 검토에서 지적되었습니다. 구분 보완과 이후 월드의 주민 후보는 [등장인물 목록](등장인물.md)에 정리했습니다. 현재 이미지 파일은 수정 전입니다.

- 나래: 갈색 단발, 꽃 장식, 살구색 옷·초록 망토, 안내 책자.
- 모아: 갈색 머리·안경, 파란 조끼, 장부·깃펜.
- 보람: 묶은 곱슬머리, 노란 앞치마, 종이·붓.
- 다온: 짙은 머리, 보라색 겉옷, 안내 카드.
- 한결: 회색 섞인 묶은 머리·안경, 초록 조끼, 확인판·필기구.

기본 표정은 역할에 맞는 친근한 모습 한 장입니다. 파일명의 neutral은 최초 기본 이미지라는 뜻이며 모두 무표정이라는 뜻은 아닙니다. 고민·축하 변형은 아직 제작하지 않았습니다.

## 화면별 분리 방식

| 화면 | 이미지 요소 | HTML/CSS·데이터 요소 | 남은 이미지 |
| --- | --- | --- | --- |
| 월드 선택 | 전체 왕국 배경, 고드래곤 | 지역 번호·이름·잠금·설명 패널·진입 버튼 | UI 없는 왕국 지도 배경 미제작 |
| 시작의 마을 | 공통 마을 배경, 고드래곤 | 5개 스테이지 카드·제목·완료 수·버튼 | 필요 시 장터 축소 삽화 |
| 이야기 대화 | 공통 배경, 고드래곤, 해당 주민 | 이름표·대사·다음·건너뛰기·발화자 강조 | 추가 표정은 필요 장면 결정 후 |
| OX·선택형 | 공통 배경, 작은 고드래곤 | 문제·OX·선택지·선택 상태·제출·해설 | 없음; 문제별 삽화 필요성 미정 |
| 카드 분류형 | 공통 배경, 작은 고드래곤 | 카드·분류 칸·이동 상태·확인 | 도구·생성 결과 삽화 후보 |
| 자료 비교형 | 공통 배경, 작은 고드래곤 | 원본·초안·상태 선택·후속 조치 | 없음 |
| 직접 대화형 | 공통 배경, 작은 고드래곤 | 과제·대화 기록·입력창·전송·상태·돌아보기 | 없음 |
| 완료·보상 | 공통 배경, 주민·고드래곤 축하 | 감사 대사·보상 값·다음 이동·복습 | 배지 이미지 미정 |

대사·문제·원본·응답·보상 값은 콘텐츠 데이터와 프로그램 상태로 관리하는 구상입니다. 창·버튼·카드는 CSS로 크기와 상태를 조절합니다. 소스코드는 이번 작업에서 작성하지 않았습니다.

## 아이콘 준비 방침 — 구현 초안

단순 기능 아이콘은 HTML/CSS 또는 개별 SVG로 준비하는 편이 적합합니다. 이미지 생성으로 글자가 포함된 버튼을 만들지 않습니다. 코드·SVG 파일 작성은 사용자님의 직접 적용 규칙에 따라 나중에 대화창으로 제공합니다.

| 아이콘 | 쓰는 곳 | 함께 표시할 문구 |
| --- | --- | --- |
| 뒤로·홈 | 화면 전환 | 스테이지 선택·홈 |
| 자물쇠·완료 체크 | 진행 상태 | 잠김·완료 |
| 책·전구 | 학습 지원 | 설명 다시 보기·힌트 |
| 화살표·보내기 | 다음·직접 대화 | 다음·보내기 |
| 자료·그림·대화·돋보기 | 유형 구분 | 유형 이름 |
| 소리 | 음향 기능을 실제 제공할 경우 | 소리 켜기·끄기 |

아이콘 제작 파일은 아직 없습니다. 아이콘만으로 버튼 기능을 전달하지 않으며, 한 스타일과 선 굵기로 통일하는 방향입니다. 생성 예시 글·그림, 장터 카드와 배지는 단순 기능 아이콘과 구분해 필요한 것만 추가 제작합니다.

## 파일과 배치 검증

- 마을 배경: 1672×940 PNG, 캐릭터·글자·버튼 없는 풍경을 시각 확인했습니다.
- 주민 5명: 각각 1024×1536 PNG, 32비트 알파 채널과 모서리 투명도를 확인했습니다. 머리·손·신발이 포함된 개별 전신을 확인했습니다.
- 주민 주변에는 부드러운 반투명 빛 번짐이 보입니다. 실제 밝은 배경 위의 합성 품질·색 테두리를 추가로 확인하고 필요하면 배경 제거 편집으로 정리합니다. 제작 완료가 곧 최종 합성 승인이라는 뜻은 아닙니다.
- 고드래곤 사본: 기본 976×1096, 나머지 2480×3508. 알파 채널·모서리 투명도를 확인했습니다. 원본마다 여백이 달라 CSS 배치 시 발 위치·보이는 크기를 맞춰야 합니다.
- 배경은 화면 크기에 맞게 배치하되 캐릭터 비율을 유지합니다. 대화 화면은 1~2명, 문제 화면은 작은 고드래곤으로 구성하는 후보입니다.
- 실제 브라우저 합성, 반응형 배치, 로딩 용량 최적화, 화면 조작 검증은 아직 수행하지 않았습니다.
